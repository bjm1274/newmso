로그아웃 버튼 색상 — accent가 danger여야 함
로그아웃 버튼이 bg-[var(--accent)]로 파란색. 파괴적 동작(로그아웃)은 반드시 danger(빨간색) 계열을 써야 UX 원칙에 맞음.

className="... bg-[var(--accent)] text-white ..."
→ 파란 로그아웃 버튼
개선 (올바름)
className="... bg-[var(--danger)] text-white hover:bg-[var(--danger-hover)] ..."
→ 빨간 로그아웃 버튼
