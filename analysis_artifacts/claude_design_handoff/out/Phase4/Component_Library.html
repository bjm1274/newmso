다크모드 자동 대응 확인 방법

우측 상단 "🌙 다크모드" 버튼 클릭 → data-theme="dark"가 <html>에 추가됨 → 모든 CSS 변수가 다크 값으로 전환. 컴포넌트 파일에는 색상 하드코딩이 없으므로 추가 수정 없이 자동 적용됩니다.
