## 개선 상세

### settings_company — 7탭 통합

#### BEFORE (#78 ~ #84)
- 각 항목 클릭 시 별도 URL로 이동 (`/admin/basic`, `/admin/work-type` 등)
- 브라우저 뒤로가기 필요 → 작업 흐름 단절
- 항목별 저장 버튼 개별 존재 → 저장 누락 위험

#### AFTER
- 단일 URL `/admin/company` + 탭 파라미터
- 탭 콘텐츠 lazy display (JS toggle) — 초기 로드 1회
- 탑바 「전체 저장」 단일 버튼으로 7개 섹션 일괄 저장
- 키보드 `ArrowLeft`/`ArrowRight` 탭 이동 (WCAG 2.1 §3.3)

---

### settings_operation — 섹션 통합

#### BEFORE (#85, #86)
- 직원권한과 운영설정이 각각 다른 페이지 → 권한 설정 후 토글 설정하려면 페이지 전환 필요
- 팝업 관리·결재양식이 운영설정 내 중첩 탭으로 숨겨져 있어 발견성 낮음

#### AFTER
- 단일 URL `/admin/operation` + 4개 섹션 수직 배치
- 섹션 헤더 sticky anchor (화면이 길어도 각 섹션 직접 접근 가능)
- 권한 변경 → 확인 모달 즉시 표시 (실수 방지)

---

### settings_template_library — 카드 그리드 통합

#### BEFORE (#87 ~ #89)
- 카테고리별 3개 페이지 분리 → 전체 템플릿 목록 파악 불가
- 검색 기능 없음
- 각 페이지에서 따로 업로드

#### AFTER
- 단일 URL `/admin/templates`
- 전체 템플릿 카드 그리드 (3열) + 카테고리 필터 (클라이언트 사이드)
- 검색 인풋 (debounce 300ms) — 템플릿명 즉시 필터
- 미리보기 → 모달 내 PDF 렌더 (새 탭 이동 불필요)
- 새 템플릿 추가 버튼 단일 진입점

## 탭릿 정책 (별도 명시)

> **Tablet (768~1023px): PC 레이아웃 그대로 축소**
>
> - 사유: 관리자 설정은 복잡한 폼·테이블 중심 백오피스 화면. 태블릿 전용 레이아웃을 별도 구성할 필요 없음.
