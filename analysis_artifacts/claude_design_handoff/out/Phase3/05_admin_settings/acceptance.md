## 2. `settings_company` — 회사정보

### 2-1. 레이아웃

| # | 기준 | 검증 |
|---|------|------|
| S-01 | 7탭(기본/근무형태/법인카드/계약/휴가/급여/문서) 모두 표시 | 탭 개수 확인 |
| S-02 | 탭 콘텐츠는 JS display 토글 — 초기 렌더 시 비활성 탭 DOM hidden | `display:none` 확인 (JM2) |
| S-03 | 탑바 「전체 저장」 버튼 항상 고정 노출 | 스크롤 후 확인 |
| S-04 | 폼 입력 배경 `--card`, 포커스 시 `--accent` 아웃라인 | 클릭 테스트 |

### 2-2. 접근성 (JM6)

| # | 기준 |
|---|------|
| S-05 | 탭 컨테이너에 `role="tablist"`, 각 탭에 `role="tab"` + `aria-selected` |
| S-06 | 각 탭패널에 `role="tabpanel"` + `aria-labelledby` 연결 |
| S-07 | 키보드 `ArrowLeft` / `ArrowRight` 로 탭 간 이동 |
| S-08 | `Home` / `End` 키로 첫 번째 / 마지막 탭 이동 |
| S-09 | `Enter` / `Space` 로 탭 활성화 |

### 2-3. 기능별 요건

**기본정보 (#78)**
- 병원명 필드 필수값(`*`) 표시 — 비어있으면 저장 시 인라인 오류 노출
- 로고/직인 업로드: 드래그앤드롭 + 클릭 모두 지원 (PNG/JPG, 최대 2MB)

**근무형태 (#79)**
- 목록에 추가·편집·삭제(soft delete) 인라인 행 가능
- 미사용 행은 시각적으로 흐리게 처리 (opacity 0.5 또는 배지)

**법인카드 (#80)**
- 카드번호는 항상 마스킹 (`****-****-****-XXXX`) — 로그/URL 노출 금지 (JM5)

**계약템플릿 (#81)**
- 미리보기 → PDF 렌더링 (iframe 또는 새 탭)
- 편집 → 리치텍스트 에디터 팝업

**휴가/공휴일 (#82)**
- 공공데이터 API 동기화 버튼 → 로딩 스피너 → 성공 토스트

**급여기준 (#83)**
- 공제 항목 세율은 직접 편집 불가 (법정 고정값) — 관리자도 읽기 전용

**문서보관 (#84)**
- 자동 삭제 토글 OFF 기본값 — 활성화 시 경고 모달 표시

## 7. 비기능 요건

- 탭 전환 렌더링 ≤ 16ms (CSS display 토글, JS 프레임 차단 없음)
- 저장 API 응답 ≤ 2s — 초과 시 로딩 스피너 표시
- 권한 변경 감사 로그: `audit_logs` 테이블에 `who / what / when` 기록
