# Before / After — work_team_share (Phase 3 · Group ⑦)

## 핵심 변경 요약

| 항목 | Before (3분할) | After (마스터-디테일) |
|---|---|---|
| **레이아웃** | 회사선택 / 자료목록 / 상세 3열 고정 | 좌 목록 + 우 상세 2분할. 목록 폭 고정(360px), 상세 가변 |
| **모바일** | 3열이 겹쳐 사실상 사용 불가 | 카드 리스트 → 슬라이드 전환 상세, 페이지 이동 없음 |
| **필터** | 별도 좌측 패널(회사·팀 선택)이 자리 차지 | 상단 breadcrumb + dropdown/chip으로 흡수, 콘텐츠 공간 확보 |
| **탭** | 자료·인수인계·할일 카운트가 분산된 위치 | 3탭 통합 + 카운트 뱃지(`.badge-blue/green/red`) 탭 안에 인라인 |
| **등록 UX** | 별도 페이지 이동 또는 전체 오버레이 | PC: 모달 / Mobile: 바텀시트 — 컨텍스트 유지 |
| **접근성** | 탭에 role 없음, 필터 레이블 없음 | `role="tablist"`, `aria-selected`, `aria-label` 전수 적용 |
| **다크모드** | 미지원 | `:root.dark` 토큰 대응, prototype 토글 확인 가능 |

## 모바일 전환 패턴 상세

- **트리거**: 카드 클릭 → `views.classList.add('show-detail')`
- **마스터**: `transform: translateX(-30%)` + `opacity: 0` (뒤로 스쳐 가는 효과)
- **디테일**: `transform: translateX(0)` + `opacity: 1` (오른쪽에서 슬라이드 인)
- **전환 시간**: `220ms ease` (`--transition-slow`)
- **복귀**: 헤더 ← 버튼 or Android popstate → `classList.remove('show-detail')`
- **헤더 변환**: "업무공유" → "자료 상세" (뒤로 버튼 노출, FAB·필터·탭 숨김)

## 빵부스러기 구조

```
MSO  ›  업무공유  ›  전체 자료함
 ↑        ↑             ↑
링크      링크        aria-current="page"
```

- `<nav aria-label="현재 위치">` 래퍼
- depth 1·2: `<a href="#">` — 클릭 시 상위 이동
- depth 3: `<span aria-current="page">` — 현재 위치 강조
- 구분자 `›` : `aria-hidden="true"` 처리

## 개선 수치

| 지표 | Before | After |
|---|---|---|
| 모바일 가용 콘텐츠 폭 | ~130px (3분할) | 390px (전체) |
| 탭 전환 비용 | 페이지 이동 또는 상태 초기화 | inline CSS transition 220ms |
| 필터 패널 점유 면적 | ~20% (좌측 1열) | 0% (상단 32px row로 흡수) |
| 접근성 누락 | tablist role 없음, 필터 레이블 없음 | WCAG AA 전수 적용 |
