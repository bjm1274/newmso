## 화면별 상세 Before / After

### 화면 1: `hr_attendance_dashboard` (근태 대시보드)

**Before — 원본 4장 (별도 화면)**

```
#30 근태 대시보드
  └─ 전체 출근 현황 요약
  └─ 부서별 통계

#35 연차휴가 목록(a)
  └─ 연차 신청 리스트
  └─ 상태 필터

#36 연차 신청(b)            ← 독립 전체 화면
  └─ 신청 폼

#37 연차 승인(c)
  └─ 승인/반려 폼

#38 연차 현황(d)
  └─ 개인 소진 현황

#39 이상감지 목록(a)
  └─ 이상 감지 리스트

#40 이상감지 상세(b)
  └─ 건별 상세 + 조치
```

**After — 1개 화면 (탭 통합)**

```
hr_attendance_dashboard
  ├─ 상단: 통계 카드 4개 (정상/지각/결근/휴가)
  └─ 내부 탭 3개
       ├─ [오늘 요약]    ← #30 흡수
       ├─ [연차 현황]    ← #35 + #37 + #38 흡수
       │    └─ "+ 연차신청" 버튼 → 모달/시트  ← #36 흡수
       └─ [이상 감지]   ← #39 + #40 흡수
```

**통합 사유**:
- 관리자는 매일 아침 한 화면에서 출근 현황 → 연차 대기 승인 → 이상 감지 확인을 순서대로 처리함
- 별도 화면 이동 시 컨텍스트 손실 발생 → 탭으로 묶어 스크롤 없이 전환 가능
- 연차 신청은 작은 폼이므로 전체 화면 대신 모달/바텀시트가 사용성 우위

### 화면 2: `hr_attendance_calendar` (근태 달력)

**Before — 원본 1장**

```
#34 근태달력
  └─ 개인 달력 1개 뷰
  (팀/연차 별도 화면 없음)
```

**After — 1개 화면 (탭 확장)**

```
hr_attendance_calendar
  ├─ 월 이동 네비게이션 (← 2026년 5월 →)
  └─ 내부 탭 3개
       ├─ [개인]   ← #34 개인 달력 그대로
       ├─ [팀]     ← 신규 추가 (팀장/관리자 권한)
       └─ [연차]   ← 연차 승인 현황 달력 뷰
  └─ 선택일 상세 사이드패널
```

**통합 사유**:
- 같은 달력 컴포넌트를 3가지 데이터 뷰로 재사용 → 중복 구현 제거
- 팀장이 팀 달력과 개인 달력을 빠르게 비교할 수 있어야 함
- 연차 달력은 별도 화면보다 달력 탭 안이 문맥상 자연스러움

### 화면 3: `hr_attendance_roster` (근무표)

**Before — 원본 3장 (별도 화면)**

```
#31 근무표 생성
  └─ 팀/기간 선택 폼
  └─ 생성 방식 선택

#32 AI 자동생성
  └─ AI 규칙 설정 폼
  └─ 생성 실행

#33 3교대 마법사
  └─ 패턴 선택 (DEN/DDEN/커스텀)
  └─ Step-by-step 설정
```

**After — 1개 화면 (액션 버튼 통합)**

```
hr_attendance_roster
  ├─ 근무표 그리드 (가로 스크롤)
  └─ 상단 액션 버튼 3개
       ├─ "+ 근무표 생성"    → 모달  ← #31 흡수
       ├─ "🤖 AI 자동생성"   → 모달  ← #32 흡수
       └─ "🔄 3교대 마법사"  → 모달  ← #33 흡수
```

**통합 사유**:
- 생성 플로우는 월 1~2회 실행되는 저빈도 작업 → 전체 화면 불필요
- 근무표를 보면서 생성 옵션을 결정하는 패턴이 자연스러움
- 3개 모달은 모두 소형 폼(4~6개 필드)이므로 dialog 요소로 충분

## 제거된 패턴과 대체

| 제거된 패턴 | 대체 방식 | 이유 |
|------------|----------|------|
| 연차 신청 전체 화면 | 모달 dialog / 바텀 시트 | 폼이 작음, 컨텍스트 유지 필요 |
| 이상감지 상세 전체 화면 | 인라인 리스트 + 확장 | 조회 중심, 별도 화면 진입 불필요 |
| 근무표 생성 전체 화면 | 모달 (단계별 옵션 포함) | 생성 옵션이 1페이지로 수용 가능 |
| AI/마법사 별도 화면 | 각각 모달로 분리 유지 | 서로 다른 설정 구조 → 통합 불가, 진입점만 통합 |
