## 화면별 Before → After 매핑

### #17 퇴원심사 메인 → PC.html / Mobile.html 목록 패널

| 항목 | Before (#17) | After |
|---|---|---|
| 역할 | 퇴원심사 진입점, 환자 목록 표시 | 목록 패널 (`ops_discharge_review_list`) |
| 위치 | 독립 페이지 | PC: 좌측 고정 패널 / Mobile: 첫 화면 |
| 검색 | 없음 | 검색 입력창 추가 |
| 상태 필터 | 없음 | 탭 필터 (전체/대기/진행/완료/반려) |
| 변경 이유 | 페이지 전환 없이 목록과 상세를 동시에 볼 수 있도록 스플릿뷰로 통합 |

### #18 새심사(a) → STEP 1 기본 정보 (상단 섹션)

| 항목 | Before (#18) | After |
|---|---|---|
| 역할 | 새 심사 등록 첫 번째 폼 (환자 기본정보) | STEP 1 "환자 기본 정보" 섹션 |
| 위치 | 별도 페이지 | 상세 패널 STEP 1 상단 카드 |
| 환자 정보 | 수동 입력 | 환자번호·이름·진료과·병실은 자동 채움(읽기 전용) |
| 퇴원 예정일 | 입력 필드 | 편집 가능 날짜 입력 |
| 변경 이유 | 사이드 패널에서 스텝 연속 진행이 가능해 컨텍스트 유지 |

---

### #19 새심사(b) → STEP 1 기본 정보 (하단 섹션)

| 항목 | Before (#19) | After |
|---|---|---|
| 역할 | 새 심사 등록 두 번째 폼 (진단·계획) | STEP 1 "진단 및 퇴원 계획" 섹션 |
| 위치 | 별도 페이지 (#18 다음) | 상세 패널 STEP 1 하단 카드 (연속) |
| 진단명 | 입력 필드 | 필수 입력 처리 + 검증 |
| 퇴원 사유 | 별도 선택 | STEP 1 내 셀렉트박스 통합 |
| 퇴원 후 계획 | 없음 | 텍스트에어리어 추가 |
| 변경 이유 | #18과 #19를 한 스텝에서 연속 입력하도록 합쳐 페이지 이동 제거 |

### #20 기본항목설정 → STEP 2 "항목 설정" 카드

| 항목 | Before (#20) | After |
|---|---|---|
| 역할 | 체크리스트 항목 추가·관리 독립 화면 | STEP 2 하단 "항목 설정" 인라인 카드 |
| 위치 | 별도 페이지 | 체크리스트 바로 아래 인라인 |
| 항목 추가 | 별도 폼 화면 | 텍스트 입력 + 추가 버튼 |
| 항목 관리 | CRUD 전용 화면 | 체크리스트와 동일 화면에서 즉시 반영 |
| 변경 이유 | 항목 설정을 체크하는 맥락 안에 두어 화면 전환 없이 수정 가능 |

---

### #21 템플릿 목록 → STEP 2 "템플릿 적용" 모달/시트

| 항목 | Before (#21) | After |
|---|---|---|
| 역할 | 저장된 체크리스트 템플릿 목록 화면 | STEP 2 "템플릿 적용" 버튼 → 모달/바텀시트 |
| 위치 | 별도 페이지 | PC: 오버레이 모달 / Mobile: 바텀시트 |
| 템플릿 표시 | 페이지 목록 | 인라인 리스트 + 추천 뱃지 |
| 적용 방법 | 페이지 이동 후 적용 | 선택 → 즉시 적용 |
| 변경 이유 | 모달/시트로 처리해 체크리스트 컨텍스트를 유지하면서 템플릿 선택 |

---

### #22 템플릿 수정 → STEP 2 "템플릿 적용" 모달 내 편집 (예약)

| 항목 | Before (#22) | After |
|---|---|---|
| 역할 | 기존 템플릿 항목 수정·저장 화면 | 모달 내 편집 기능 (추후 확장 영역) |
| 위치 | 별도 페이지 | 모달 내 "편집" 버튼 → 인라인 편집 (v2 예정) |
| v1 처리 | — | 템플릿 적용 후 항목 설정 카드에서 직접 수정 가능 |
| 변경 이유 | v1에서는 "적용 후 인라인 수정" 패턴으로 대체, 별도 템플릿 관리 화면은 v2에서 관리자 전용으로 추가 |

## 정보 구조 비교

```
Before (6장)
├── #17 퇴원심사 메인 (목록)
├── #18 새심사(a) (환자 기본정보 폼)
├── #19 새심사(b) (진단·계획 폼)
├── #20 기본항목설정
├── #21 템플릿 목록
└── #22 템플릿 수정

After (2장)
├── ops_discharge_review_list (목록)
│   └── 환자 카드 · 상태 뱃지 · 탭 필터 · 검색
└── ops_discharge_review_detail (상세 — 스텝)
    ├── STEP 1: 기본 정보
    │   ├── 환자 기본 정보 카드  ← #18 흡수
    │   └── 진단 및 퇴원 계획 카드  ← #19 흡수
    ├── STEP 2: 항목 체크
    │   ├── 퇴원 체크리스트  ← #17 일부 흡수
    │   ├── [템플릿 적용] 버튼 → 모달/시트  ← #21, #22 흡수
    │   └── 항목 설정 카드  ← #20 흡수
    └── STEP 3: 결재
        ├── 결재 요약
        └── 결재선
```

## 제거된 페이지 이동

| Before 페이지 전환 | After 처리 |
|---|---|
| 메인 → 새심사(a) | 목록에서 "새 심사 등록" → 같은 화면 STEP 1 |
| 새심사(a) → 새심사(b) | STEP 1 단일 스크롤 (스텝 내 연속) |
| 새심사(b) → 기본항목설정 | STEP 2 내 "항목 설정" 카드 |
| 항목설정 → 템플릿 목록 | STEP 2 내 모달 |
| 템플릿 목록 → 템플릿 수정 | 모달 내 편집 또는 인라인 수정 |

**총 5회 페이지 이동 → 0회** (전체 클라이언트 스텝 전환)
