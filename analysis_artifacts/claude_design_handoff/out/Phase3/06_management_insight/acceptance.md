### 레이아웃 기준

#### PC (Desktop First)
- [ ] KPI 카드 4~6개, 자동 피드 그리드
- [ ] 차트 영역 2단(월별 매출, 이익률 + 입원율, 부서별)
- [ ] 상단 위젯 토글 버튼 (KPI / 매출·이익 / 환자 / 예산 / 상세표)
- [ ] 하단 표 (법인·부서별 7열: 법인명, 부서, 매출, 이익, 이익률, 환자, 상태)
- [ ] 토글 상태 유지 (localStorage)

#### Mobile (375px 최소)
- [ ] KPI 카드 2열 또는 단열, 반응형
- [ ] 핵심 그래프만: 월별 매출, 이익률, 입원·외래, 부서별 환자, 예산집행률
- [ ] 상세표는 축약(부서, 매출, 이익, 상태만)
- [ ] 터치 친화적(버튼 44px+, 간격 12px+)

#### Tablet (768px)
- [ ] PC 축소본: KPI 2열, 차트 1열 스택
- [ ] 여전히 모든 기능 유지

### 디자인 시스템 적용

#### CSS 변수 & 색상
- [ ] `--accent` (#2563eb) 사용
- [ ] `--success` (#10b981), `--danger` (#ef4444) 추세 표시
- [ ] `--radius-lg` (12px) 카드, `--radius-md` (8px) 버튼/배지
- [ ] `--card`, `--muted`, `--border` 활용
- [ ] 다크모드: `@media (prefers-color-scheme: dark)` 적용

#### 폰트
- [ ] Pretendard 웹폰트 임포트
- [ ] 사이즈: h1 26~28px, h3 14px, body 13px, badge 10~11px
- [ ] font-weight: 700(헤더), 600(소제목), 500(라벨)

#### 컴포넌트
- [ ] KPI 카드: 라벨 + 값(28px) + 변화(12px)
- [ ] 배지: `.badge-blue`, `.badge-green`, `.badge-red`, `.badge-yellow`, `.badge-gray`
- [ ] 표: thead 배경색, hover 상태, border-collapse

### 접근성 (WCAG AA)

#### 시맨틱 & ARIA
- [ ] `<figure>`, `<figcaption>` SVG/차트용
- [ ] `aria-label="월별 매출: 1월 180M, 2월 195M..."` (차트용)
- [ ] `<table>` 또는 `role="table"`
- [ ] `<header>`, `<section>`, `<main>` 적절히 사용
- [ ] 버튼: `onclick` + `onkeydown` (Space, Enter)

#### 키보드 네비게이션
- [ ] Tab 순서: 위젯 토글 → 표 셀
- [ ] 버튼: Space/Enter로 토글
- [ ] 링크/클릭 요소 모두 focus 보임
- [ ] focus-visible 스타일 (파란 테두리)

#### 색상/대비
- [ ] 텍스트 대비: 4.5:1 이상 (본문 13px)
- [ ] 상태 표시는 색상만 아님: 텍스트(↑/↓) + 색상
- [ ] 차트 범례: 색상 + 텍스트

#### 스크린 리더
- [ ] `role="img"` 차트에 대체 텍스트(`aria-label`)
- [ ] 표 헤더: `<th>` 및 `scope="col"`
- [ ] 형식: "월별 매출: 1월 180M, 2월 195M..."

### 기능 요구사항

#### 위젯 토글
- [ ] PC 상단: 5개 버튼 (KPI / 매출·이익 / 환자 / 예산 / 상세표)
- [ ] 클릭하면 해당 섹션만 표시/숨김
- [ ] 활성 버튼: `--accent` 배경, white 텍스트
- [ ] localStorage에 상태 저장 (세션 유지)

#### 그래프 유형
- [ ] **막대**: 월별 매출, 부서별 환자, 예산 항목(div 그리드)
- [ ] **라인**: 이익률 추이(SVG 또는 div 점)
- [ ] **원형 분할**: 입원·외래 비율(flex 비율 높이)
- [ ] 모두 `<figure>` 래핑, aria-label 포함

#### 데이터 표시
- [ ] 모든 수치는 **더미** (실제 매출 금지 — JM5)
- [ ] 형식: ₩245.8M (매출), 15.5% (률), 1,707명 (환자)
- [ ] 변화율: ↑ 12.5% YoY, ↓ 2.1% YoY

#### 권한 표시
- [ ] 접근 제한: 관리자(ROLE=관리자) 또는 원장(ROLE=원장)만
- [ ] 현재 UI에는 로그인/권한 체크 없음 → prototype 범위
- [ ] 실제 구현에서: `useRole()` hook 또는 `canAccess('mgmt_insights')`

### 다크모드

- [ ] `prefers-color-scheme: dark` 미디어 쿼리
- [ ] 배경: `--card` (light: white, dark: #1f2937)
- [ ] 텍스트: `--foreground` (light: #1f2937, dark: #f3f4f6)
- [ ] 표, 카드, 버튼 모두 다크모드 대응
- [ ] 차트 배경: `--muted`

## 기능 검증 (수락 테스트)

### 비용 시나리오

#### 시나리오 1: 관리자, PC, 밝은 테마
1. PC.html 로드
2. 전체 위젯 표시 (KPI, 매출, 환자, 예산, 표)
3. "매출·이익" 버튼 클릭 → 해당 차트만 표시
4. 토글 상태 localStorage 저장
5. 새로고침 → 이전 선택 유지
6. 다크모드 전환 → 색상 변경 (텍스트, 배경, 테두리)

#### 시나리오 2: 모바일, 세로 방향
1. Mobile.html 로드 (375px)
2. KPI 카드 2열 표시
3. 월별 매출, 이익률, 입원·외래, 부서별, 예산 그래프만
4. 표: 부서, 매출, 이익, 상태(4열만)
5. 터치 스크롤 가능

#### 시나리오 3: 프로토타입, 대화형
1. prototype.html 로드
2. KPI 섹션 활성
3. "매출" 버튼 → 수익 섹션 전환, 테이블 표시
4. "환자" 버튼 → 차트 + 테이블
5. KPI 카드 클릭 → alert("상세 정보 모달")

#### 시나리오 4: 접근성 (키보드)
1. Tab 키: 토글 버튼들 포커스
2. Space/Enter: 버튼 활성화
3. 스크린 리더: `aria-label="월별 매출: 1월 180M..."` 읽음
4. 표: "내과, 부서, 85.2M, 12.8M, 15.0%, 340, 정상"

## 거절 기준 (Red Flags)

- [ ] 특정 수치가 실제 데이터(매출금액, 환자명, 상호명)인 경우
- [ ] PC 없이 Mobile만 제공된 경우
- [ ] 위젯 토글 기능 없음
- [ ] `any` 타입 사용 또는 런타임 검증 부족
- [ ] 색상만으로 상태 표시 (텍스트 없음)
- [ ] 1200줄 초과
- [ ] 다크모드 미지원
- [ ] 키보드 네비게이션 불가
- [ ] 차트에 `aria-label` 없음
- [ ] 권한 체크 UI 없음(원장·관리자 제한 표시)
