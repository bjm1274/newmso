## 핵심 디자인 변경

### Before
- 채팅: 드로어/패널/타임라인이 각각 별도 컴포넌트, 진입점이 분산
- 내정보: 6개 독립 화면, 탭 이동 많음
- 출퇴근 체크인 버튼: 일반 크기 (~40px)
- 할일: 단순 리스트, 우선순위 미구분

### After
- 채팅: 단일 라우트(`/work/chat`), 모바일은 방목록↔대화창 풀스크린 전환, PC는 Split View 고정
- 내정보: 3개 화면 + 서류제출 모달, 마이페이지 메인에서 모든 핵심 정보 1뷰 확인
- 출퇴근 체크인 버튼: **64px h** (WCAG 2.5.5 초과 충족, 오터치 방지)
- 할일: 필터탭 + 우선순위 뱃지 + FAB + 바텀시트 새 할일 입력

### 채팅 가상 스크롤 패턴
```
[메시지 영역 role=log]
  ↑ vs-top-sentinel div  ← IntersectionObserver가 감시
  [이전 메시지 청크 (필요 시 prepend)]
  [현재 50개 메시지 렌더]
  ↓ 새 메시지 자동 스크롤 (scrollTop = scrollHeight)

로직:
  - 최초 로드: 최신 50개 렌더
  - 상단 스크롤 → sentinel intersect → 이전 50개 prepend 요청
  - DOM 누적 방지: 150개 초과 시 하단 오래된 노드 제거 (실 구현 시)
```

### 바텀탭 통합 위치
```
바텀탭 4개 (모바일 / 태블릿 공통):
  [💬 채팅]  [👤 내정보]  [🕐 출퇴근]  [✅ 할일]
  
  기존 ERP 좌측 사이드바 메뉴에서 분리 →
  내정보 그룹 전용 바텀탭으로 격하 (모바일 UX 최적화)
  PC에서는 기존 사이드바 + 서브메뉴 유지
```
