04공통 패턴 — 모든 메뉴에서 동일하게 구현
기준 3종에서 검증된 7개 공통 패턴. 새 PR마다 이 패턴 외에 새로운 변형을 추가하지 말 것.
①
PageHeader 컴포넌트 — 모든 화면 최상단은 <PageHeader title subtitle actions />로 통일. title 20/800, subtitle 12/500 muted, actions는 오른쪽 정렬 버튼 슬롯. 화면별 별도 JSX 금지.
②
Lucide 아이콘만 사용 — 이모지(👤📋💬 등) 전면 제거. 메뉴/탭/상태/장식 어디서든 lucide-react의 컴포넌트만 사용. 크기는 메뉴 18px, 서브메뉴 13px, 인라인 본문 14px, 데코 카드 20px.
③
섹션 헤더 — 캡션 스타일 — border-l-4 + accent 패턴 폐기. 대신 10/700 uppercase tracking-wider, color: fg-subtle 캡션 라벨로 통일.
④
탭바 — segmented control — 내정보의 p-1 bg-bg rounded-xl + 활성 bg-card shadow-sm 패턴을 게시판/전자결재/관리자에도 동일하게 적용. 탭마다 Lucide 아이콘 + 한글 라벨.
⑤
InfoItem 행 — label(11/600 muted) ┃ value(13/600 fg) 좌우 정렬. value는 절대 15px 이상 금지(기준 위반).
⑥
상태 배지(.badge) — globals.css의 .badge.badge-green / -red / -yellow / -blue / -gray만 사용. emerald/rose/amber Tailwind 클래스 직접 사용 금지.
⑦
QuickAction 그리드 — 추가기능과 동일 4열(모바일 3열) 정사각 카드. 아이콘 컨테이너 38×38 bg: accent×8% opacity, 한 줄 한글 레이블. 게시판 새 글쓰기·인사관리 결재 빠른메뉴 등에 재사용.

F-01 · 페이지 헤더 3가지 패턴 공존 치명
① 텍스트만 — 채팅·게시판·재고 “재고 현황·구매/발주”
② 텍스트 + 배지 — 전자결재 “결재함 [0건]”, 인사관리 “실시간 구성원 현황 [전체]”
③ 아이콘 박스 + 텍스트 + 배지 — 인사관리 “전문 근태 통합 관리” (보라/푸른 그라데이션 박스)
→ 같은 메뉴 안의 인력관리·근태·급여 세 화면조차 헤더 패턴이 다름.
F-02 · 버튼 색상 의미 깨짐 치명
한 화면(인사관리 구성원 테이블) 안에서 5색 액션 버튼이 의미 없이 혼재:
· 신규 직원 등록 = primary
· 수정 = ??? (왜 검정?)
· 삭제 = danger soft
· 문서 = secondary
· 재고관리 발주 처리 = 또 다른 danger
F-03 · 빈 상태(Empty) 3가지 패턴 높음
· 채팅 메인: 아이콘 + “채팅방을 선택하세요.” 회색
· 채팅 박민지: 아이콘 + “대화 내용이 없습니다.” (사이즈/위치 다름)
· 전자결재: 배지 “빈 상태” + 제목 + 부제 2줄 (완전 다른 패턴)
· 게시판·재고: 빈 상태 자체 부재
F-04 · 검색 위치·형태 4종 높음
· 채팅 상단: 돋보기 아이콘 버튼만 (모달 트리거)
· 인사관리: 우측 “직원 검색” input + 별도 “검색” 버튼
· 재고관리: 전체 너비 input + 부가 dropdown 2개
· 전자결재: 필터 4종(전체 문서/전체/주간별/검색) 한 줄
→ 글로벌 검색이 메인 앱바에 없음. GlobalSearch.tsx가 있는데도 화면별 자체 검색 4종.
F-05 · 좌측 sub-nav 그룹화 3종
· 게시판·전자결재: 평평한 메뉴 (그룹 없음)
· 인사관리: 큰 박스 + 배지(ESS/퇴사 검토, 급여 확정 검토 등) + 안에 sub-nav
· 재고관리·관리자: 소문자 회색 그룹 라벨(“운영/기준/마감”) + 단순 리스트
→ 통일 후보: 인사관리 패턴은 너무 과함, 재고·관리자 패턴이 표준에 적합
F-06 · KPI 카드 3가지 변형
· 전자결재 결재함: 우측 상단 아이콘만 (대기중/이번달 승인/반려)
· 재고 현황: 좌측 컬러 강조선 + 우측 상단 아이콘
· 구매/발주: 좌측 컬러 강조선만
· 관리자 경영분석: 우측 상단 아이콘만 (재고 현황과 다름)
→ 같은 도메인(재고관리) 안에서 두 패턴 공존
F-07 · 탭·세그먼트 5종

M6 · Form
폼 입력 단일 컬럼
