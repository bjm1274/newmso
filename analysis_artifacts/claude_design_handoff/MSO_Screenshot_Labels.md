## 분포 요약

- 내정보: 6장 (#01-06)
- 추가기능: 16장 (#07-22) — OP체크 5장, 퇴원심사 6장이 가장 큼
- 게시판: 2장 (#23-24)
- 전자결재: 2장 (#25-26)
- 인사관리: 37장 (#27-63) — 가장 방대. 급여만 13장
- 재고관리: 7장 (#64-70)
- 관리자: 26장 (#71-96) — 회사관리 7장, 운영설정 4장

## 핵심 관찰

1. **인사관리(37)+관리자(26)=63장 = 전체의 66%** — 백오피스 ERP 비중 압도적
2. **급여 13개 화면** — 단일 서브메뉴 중 최대. 통합 가능성 매우 높음
3. **퇴원심사 6개 화면** — 워크플로우 한 흐름. 모달/스텝으로 통합 가능
4. **OP체크 5개 화면** — 상태 전이만 다른 동일 화면 (메인/환자/준비/시작/완료)
5. **연차휴가 4장 + 근태이상감지 2장** — 탭 통합 후보
6. **운영설정 템플릿 3장 + 회사관리 계약템플릿** — 템플릿 시스템 중복
7. **경조사 2장(관리/등록), 마감보고 2장(목록/생성)** — CRUD 짝
