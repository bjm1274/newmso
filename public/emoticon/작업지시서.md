# 작업지시서 — 애니메이션 채팅 이모티콘 (직장인 / 의료진)

> 이 문서는 후속 작업자(Gemini 등)가 본 프로젝트를 **이해하고 확장**할 수 있도록 작성한 지시서입니다.
> 모든 이모티콘은 손으로 한 개씩 그리지 않고 **파라메트릭 엔진**(`emoticon-face.js`)이 표정·헤어·유니폼·소품·효과를 조합해 SVG로 생성합니다.

---

## 1. 프로젝트 개요

- **목표**: 채팅방에서 쓰는 **애니메이션 이모티콘 40종** (직장인 컨셉 20 + 의료진 컨셉 20)
- **디자인 방향**: 라인아트 사람 캐릭터 · 밝은 파스텔 톤 · "통통 튀는" 과장된 움직임 · 한국어 텍스트 라벨
- **결과물**
  - `이모티콘 채팅.html` — 회사방/병동방을 전환하며 이모티콘을 실제로 보내보는 프로토타입(상대 자동 답장 포함)
  - `이모티콘 갤러리.html` — 40종을 한눈에 보는 리뷰 페이지
- **실행 방법**: 두 HTML 중 아무거나 브라우저로 열면 됨(빌드/서버 불필요, 순수 HTML+CSS+JS). 단, 같은 폴더에 아래 파일들이 모두 있어야 함.

---

## 2. 파일 구조 / 역할

| 파일 | 역할 |
|---|---|
| `emoticon-face.js` | **핵심 엔진**. `buildEmoticonSVG(def)` 가 정의(def) 객체를 받아 캐릭터 SVG 문자열을 생성. 눈/입/눈썹/헤어/유니폼/소품/효과 빌더 포함 |
| `data-office.js` | 직장인 20종 데이터 배열 `window.EMO_OFFICE` |
| `data-hospital.js` | 의료진 20종 데이터 배열 `window.EMO_HOSPITAL` |
| `styles.css` | 이모티콘 기본 스타일 + **애니메이션 키프레임**(메인 동작 + 서브파트 효과) |
| `chat-ui.css` | 채팅 프로토타입 UI 레이아웃 |
| `chat-app.js` | 채팅 로직(방 전환, 메시지 렌더, 전송, 자동답장, 트레이, 갤러리 오버레이) |
| `이모티콘 채팅.html` | 채팅 프로토타입 진입점 |
| `이모티콘 갤러리.html` | 갤러리 진입점 |

스크립트 로드 순서(중요): `emoticon-face.js` → `data-office.js` → `data-hospital.js` → `chat-app.js`

## 3. 이모티콘 정의(def) 스키마

각 이모티콘은 아래 형태의 객체 한 개입니다.

```js
{
  id: "o-coffee",            // 고유 id (office=o-, hospital=h- 접두사)
  label: "커피수혈",          // 채팅/갤러리에 표시되는 한국어 라벨
  group: "office",           // "office" | "hospital"
  anim: "a-pulse",           // 메인 애니메이션 클래스 (아래 5번 표)
  uniform: "suit",           // 상반신 유니폼 (아래 4번)
  front: ["coffee"],         // 앞쪽 소품 배열 (캡/손에 든 것 등, 아래 4번)
  face: {
    skin: "#ffe0c2",         // 피부색
    hair: "short",           // 헤어스타일 (아래 4번)
    hairColor: "brown",      // 헤어색 (아래 4번)
    tieColor: "#6f9bd1",     // (정장/셔츠) 넥타이색, (가운) 펜색
    glasses: true,           // 안경 on/off (선택)
    eyes: "shine",           // 눈 (아래 4번)
    mouth: "smile",          // 입 (아래 4번)
    brow: "worried",         // 눈썹 (선택, 아래 4번)
    blush: true,             // 볼터치 (선택)
    fx: ["sparkles"]         // 효과 배열 (아래 4번)
  }
}
```

> ⚠️ `mask` 소품을 쓸 때는 입이 가려지므로 `face.mouth: "none"` 으로 설정.

## 4. 사용 가능한 옵션 카탈로그 (엔진이 지원하는 값)

**eyes**: `dot` `shine`(반짝 큰눈) `happy`(^^) `smile`(‿‿) `sleepy` `wide`(놀란 흰자) `x`(지침) `dizzy`(소용돌이) `star` `heart` `money`(₩) `wink` `cry`(글썽) `angry` `side`(곁눈질) `blank`(멍)

**mouth**: `none` `smile` `small` `bigsmile` `grin`(이) `open`(O) `gasp`(큰O) `frown` `flat` `wavy`(불안) `smallo` `cat`(ω) `tongue` `yawn` `gritted`(악) `smirk`

**brow**: `none` `angry` `worried` `raised` `flat`

**hair**: `short` `sidepart`(가르마) `bob`(단발) `ponytail` `bun`(올림머리) `quiff`(올백앞머리) `buzz`(짧은머리) `baldsides`(반백/M자) `none`
**hairColor**: `dark` `brown` `lbrown` `auburn` `gray` `soft`

**uniform**: `suit`(남색정장+넥타이) `shirt`(셔츠+넥타이) `scrubs`(청록 수술복+청진기) `coat`(흰 가운+청진기)

**front 소품**: `coffee` `clipboard` `syringe` `pills` `doc`(서류) `phone` `fist`(주먹) `mask` `capdoc`(수술캡) `capnurse`(간호사캡) `clock` `lanyard`(사원증)
> 손에 드는 소품(coffee/clipboard/syringe/pills/doc/phone)은 머리 옆에 손과 함께 그려짐. 캡은 머리 위.

**fx 효과(애니메이션 포함)**: `sweat` `sweat2`(땀 2방울) `tears`(주르륵) `tearjoy`(감동눈물) `anger`(💢핏대) `steamhead`(분노김) `zzz` `sparkles` `moon` `heartup`(하트 떠오름) `note`(♪콧노래) `question`(?) `exclaim`(!) `alarm`(!!) `bubble`(거품) `lines`(우울세로줄) `flypaper`(날리는 서류)

## 5. 애니메이션 클래스 (anim)

`styles.css`에 정의됨. 메인 캐릭터에 적용:

`a-bounce` `a-jump` `a-shake` `a-wobble` `a-spin` `a-pulse` `a-float` `a-nod` `a-vibrate` `a-tilt` `a-droop` `a-swing`

서브파트(땀/눈물/김/반짝이 등)는 fx 마크업 안에 자체 클래스로 이미 포함되어 자동 재생됩니다.

## 6. 좌표 시스템 (엔진 내부, viewBox 100×100)

```
머리 중심  CX=50, CYH=39, 반지름 R=24   (머리 꼭대기 y≈15, 턱 y≈63)
눈        LX=41, RX=59, EY=40
입        MY=52
목/상반신  y56~100
```
신규 표정/소품을 추가할 때 이 상수를 기준으로 배치하세요(`emoticon-face.js` 상단에 정의).

## 7. 새 이모티콘 추가하는 법 (예시)

`data-office.js` 또는 `data-hospital.js` 배열에 객체 하나 추가하면 끝(갤러리·채팅 트레이에 자동 반영):

```js
{ id:"o-lunchdone", label:"점심뿌듯", group:"office", anim:"a-bounce", uniform:"suit",
  face:{ skin:"#ffe0c2", hair:"short", hairColor:"brown", tieColor:"#5fae8c",
         eyes:"happy", mouth:"bigsmile", blush:true, fx:["sparkles"] } }
```

새로운 **표정/소품/헤어/효과 종류**가 필요하면 `emoticon-face.js`의 해당 `switch` 문(`eyes()`, `mouth()`, `brow()`, `hair()`, `prop()`, `fx()`)에 `case`를 추가하세요. 새 **애니메이션**은 `styles.css`에 `@keyframes` + `.a-*` 클래스로 추가합니다.

## 8. 채팅 프로토타입 구조 (`chat-app.js`)

- `ROOMS` 객체: 방 2개(`office`, `hospital`)의 이름/봇 이름/시드 메시지/자동답장 텍스트·이모티콘 정의
- 이모티콘 클릭 → 내 말풍선으로 전송 → 타이핑 인디케이터 → 봇이 텍스트/이모티콘으로 자동 답장
- 헤더 "전체보기" → 40종 갤러리 오버레이
- `history` 객체로 방별 대화 유지(메모리 내)

## 9. Gemini에게 요청할 수 있는 후속 작업 예시

1. **라벨/상황 교체**: `data-*.js`의 `label`과 표정 조합을 원하는 감정으로 수정
2. **캐릭터 다양화**: `hair`/`hairColor`/`skin`/`glasses`를 바꿔 성별·연령대 폭 확대
3. **세트 추가**: 같은 엔진으로 3번째 컨셉(예: 교사, 카페 알바) 데이터 파일 추가
4. **내보내기**: 각 이모티콘을 투명 PNG/APNG/GIF로 추출하는 스크립트 작성(아래 10번 참고)
5. **표현력 강화**: 새 `eyes`/`mouth`/`fx` case 추가, 새 `@keyframes` 추가

## 10. 이미지(PNG/GIF)로 내보내기가 필요할 때 (가이드)

현재는 **웹 인라인 SVG + CSS 애니메이션**입니다. 실제 이모티콘 상품(투명 배경 정지/움직이는 이미지)이 필요하면:
- 정지 PNG: 각 def를 `buildEmoticonSVG`로 그려 `<svg>`를 캔버스에 렌더 후 `toBlob('image/png')`
- 움직이는 이미지: 애니메이션 프레임을 일정 간격으로 캡처해 APNG/GIF/WebP로 합성(예: gif.js, 또는 헤드리스 브라우저 캡처)
- 권장 사이즈: 360×360 px, 투명 배경

---

## 11. 코딩 규칙 / 주의사항

- SVG는 손으로 복잡하게 그리지 말고 **엔진 빌더 함수**를 통해서만 생성(일관성 유지)
- 색상은 `emoticon-face.js` 상단 `C`(팔레트), `HAIRC`(헤어), `SKIN`(피부) 상수에서 관리
- 파일은 UTF-8, 한국어 라벨 사용
- `prefers-reduced-motion` 사용자를 위해 애니메이션 자동 축소 처리되어 있음(`styles.css` 하단)
- 스크립트 로드 순서를 지킬 것(2번 참고)
