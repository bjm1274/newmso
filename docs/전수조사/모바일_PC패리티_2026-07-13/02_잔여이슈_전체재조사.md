## 2. 이미 해결 — 재보고 제외

- 개인 연차 SSOT (`useAnnualLeaveSummary`) · 반차 year clip · 15일 폴백 제거 (홈/내정보/PC 마이페이지)
- 게시판 free 강제 해제 · 제안함/익명소리함 메뉴 삭제 · 보드별 병렬 로드 · **칩 카운트 캐시**
- 알림 → 결재 `detail:` / 게시글 sessionStorage
- 채팅 `room:` 딥링크 + resetToken 예외
- 사진 업로드 · 서류제출 · 근태이상 허브 · 체크인 KST · Gemini/ESL PC 표기
- 인사/결재 핵심 경로 `useResolvedStaffId` 일부 적용

## 3. Critical (우선 수정 권장)

### C1. 재고 — 회사 필터 누락 (타 법인 데이터 혼입)

| 화면 | 파일 | 문제 |
|------|------|------|
| 허브 KPI / 재고현황 | `useStatusData(company)` | ✅ 필터 있음 |
| **입출고** | `입출고.tsx` → `useIOData()` | ❌ company 미전달 |
| **물품·자산** | `물품자산.tsx` → `useItemData()` | ❌ |
| **분석·마감** | `분석마감.tsx` → `useAnalyzeData()` | company는 헤더만 |

**체감:** 현황 숫자 ≠ 입출고/물품 목록. 다회사 시 타사 재고 노출.

---

### C2. 연장근무 폼 — 스키마에 없는 컬럼

**파일:** `모바일/결재/연장근무폼.tsx`  
조회: `attendances` + `overtime_minutes`, `check_in_at`, `check_out_at`  
스키마 실제: `check_in_time` / `check_out_time` (overtime_minutes 없음)

**체감:** “연장근무 이력 없음” 고착 · 상신 불가에 가깝다.

---

### C3. 입금조회 · 마감보고 — 회사 미격리

**파일:** `추가기능/data-hooks.ts`  
- `useDeposits`: `void company` 후 전 회사 조회  
- `useClosingToday`: 일자만, company_id 미적용  

**체감:** 타사 입금/마감 노출 가능.

## 4. Major

### M1. staffId = raw `user.id` 잔존 (쓰기·민감)

`useResolvedStaffId` 적용된 곳: 결재 핵심 폼 · 인사 index · 알림탭 · Shell · 홈 등  

**미적용 예:**

| 영역 | 파일 |
|------|------|
| 증명서 | `내정보/증명서.tsx` |
| 알림설정 푸시 | `알림설정.tsx` |
| 복지 서류 업로드 | `인사관리/복지.tsx` |
| 채팅 전송/방 | `채팅방.tsx`, `새대화.tsx` 등 |
| 게시 작성 author | `글작성.tsx` |
| 추가기능 다수 | 수술상담 · 인계 · 평가 · 업무공유 · 퇴원 · OP |
| 재고 발주 | `발주등록.tsx` created_by |

세션 id = staff UUID면 증상 없음. **불일치 계정에서만** 발급/푸시/채팅 깨짐.

---

### M2. 근태 테이블 읽기 불일치

| 화면 | 테이블 |
|------|--------|
| 체크인 쓰기 | `attendance` + sync attendances |
| 내정보/인사 월집계 | **attendance만** |
| 근태관리자 | **attendances만** |
| 근무현황 / 출결정정 | 둘 다 병합 ✅ |

sync 지연 시 관리자 ↔ 본인 화면 숫자 어긋남.
