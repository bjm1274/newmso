## 1. 한 줄 결론

**메뉴 골격(9탭·인사·재고·결재·관리자)은 PC와 대체로 대응**하나, 체감 핵심인 **잔여 연차·사용 내역 숫자**는 현재 코드에서도 **화면마다 다른 테이블·공식을 사용**한다.  
어제(07-12) Sprint로 게시판 free 강제·근무현황 전원 근무중·생체 우회·바텀탭 권한 등 Critical 일부는 **수정됨**.  
**남은 1순위는 연차 SSOT 통일 + 내정보 메뉴/딥링크/사진 변경**이다.

## 3. Critical: 잔여 연차 SSOT 붕괴 (최우선)

### 3.1 동일 사용자가 보는 숫자가 화면마다 다른 이유

| # | 화면 | 훅/위치 | total 소스 | used 소스 | 소멸·보상(E/C) | remaining 공식 |
|---|------|---------|------------|-----------|---------------|----------------|
| 1 | **모바일 내정보 홈** KPI | `useLeaveBalance` + `홈.tsx` | `leave_balances.total_days` 우선, 없으면 `user.annual_leave_total \|\| **15**` | `leave_balances.used_days` 또는 user | O | `T−U−E−C` |
| 2 | **모바일 내정보 → 연차** | `useMyLeave` | `staff_members.annual_leave_total` (**15 폴백 없음 → 0**) | `max(staff.used, ledger 재집계)` | O (당해 year) | `T−U−E−C` |
| 3 | **모바일 인사관리 → 연차** | `useMyLeaveBalance` | staff only | staff only | **없음** | `T−U` 만 |
| 4 | **PC 마이페이지 홈 KPI** | `마이페이지/index.tsx` | `user.annual_leave_total \|\| **15**` | `user.annual_leave_used` (재계산 없음) | O | `T−U−E−C` |
| 5 | **PC 연차휴가내역** | `연차휴가내역.tsx` | staff → user 폴백 | `max(staff.used, ledger)` | O | `T−U−E−C` |

**서버 SSOT 참고:** `lib/annual-leave-balance.ts` (accruals + sync used + leave_balances UPSERT).  
UI 5경로는 이 SSOT를 **공유하지 않음**.

### 3.2 재현 시나리오 (숫자 예시)

| 조건 | 모바일 홈 | 모바일 연차 상세 | 인사 연차 | PC 홈 | PC 연차내역 |
|------|-----------|------------------|-----------|-------|-------------|
| staff total=null, used=0 | **15일** | **0일** | **0일** | **15일** | **0일** |
| total=15, used=5, expired=3 | leave_balances 있으면 그 값 | 7 (ledger 반영) | **10** (E 무시) | 7 | 7 |
| leave_balances total=12, staff=15 | **12** 계열 | **15** 계열 | **15** | 15 계열 | 15 계열 |

### 3.3 반차·사용 내역 표시 불일치

| 항목 | PC `연차휴가내역` | 모바일 `useMyLeave` | 모바일 HR |
|------|-------------------|---------------------|-----------|
| 반차 used 합산 | 0.5 (ledger) | 0.5 (ledger max 경로) | staff 컬럼만 |
| 반차 목록 | 연차 **또는** 반차 | `isAnnualLeaveType`만 → **「반차」단독 제외 가능** | 포함 |
| 반차 일수 표시 | 0.5 | `calculateLeaveDays` → **1일 오표기** | 월 차트 1건=1 |
| status 필터 | **승인만** | 승인+대기+반려 | 전부 |
| limit | 무제한 order | 50건 | 30건 |

### 3.4 연차 신청 한도 위험 (High)

`useMyLeaveBalance`를 쓰는 곳:

- `인사관리/연차.tsx`
- `인사관리/연차신청.tsx`
- `결재/연차계획폼.tsx` ← 잔여일수만큼만 선택

→ **소멸·수당 미반영 시 실제 잔여보다 많이 신청 가능** (예: 정답 7일인데 UI 10일).

### 3.6 권장 수정 (단일 훅)

```text
// 전 UI 공용 권장
total     = leave_balances.total_days     ?? staff.annual_leave_total ?? 0   // 15 폴백 금지(또는 전역 정책 문서화)
used      = leave_balances.used_days      ?? max(staff.used, ledger(year))
expired   = leave_balances.expired_days   ?? 0
compensated = leave_balances.compensated_days ?? 0
remaining = max(0, total − used − expired − compensated)
// 또는 remaining_days 직독 (recalculate 직후 신뢰 시)

히스토리: 승인 + (연차 | 반차), 일수 = isHalfLeaveType ? 0.5 : calculateLeaveDays
staffId: resolveStaffLike / getStaffLikeId (PC와 동일)
```

적용 대상: 모바일 홈 · 내정보 연차 · HR 연차 · 연차신청 · 연차계획 · **PC 홈 KPI** · PC 연차패널.
