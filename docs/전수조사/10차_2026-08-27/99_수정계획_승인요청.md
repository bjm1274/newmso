| **`D1GW-01`** | `onConflict:'replace'` 를 **항상 id 충돌로 가정**해, id 없는 upsert 는 새 가드를 건너뛴다. 모바일 OP체크에서 체크 하나 토글하면 **PC 에서 입력한 환자명·수술명·마취종류·상태가 전부 초기화**되고 행 id 도 바뀐다. FB7 이 막으려던 정책 우회도 이 경로로는 그대로 열려 있다(회사 경계 넘음) |
| `D1GW-02` | 행-무관 패턴(`ADMIN_ONLY`·`ADMIN_OR_MANAGER`)에도 행마다 SELECT 가 붙어 근무표 일괄저장·복원이 느려진다 |

**수정**
1. `resolveUpsertConflictColumns` 가 `'replace'` 를 **id 로 단정하지 않게** 한다. 대상 테이블의 실제 UNIQUE 제약을 보거나, 충돌 키를 특정할 수 없으면 **거부**한다(지금은 통과시킨다).
2. 모바일 OP체크 저장이 `{ onConflict: 'schedule_post_id' }` 를 넘기게 한다 — **PC 형제 경로 3곳은 이미 그렇게 부르고 있다.**
3. `rowIndependent` 단축 경로에 `ADMIN_ONLY`·`ADMIN_OR_MANAGER` 를 추가한다.

**회귀위험이 낮은 이유**: 2는 PC 와 동일하게 맞추는 것이고, 3은 판정에 영향을 줄 수 없는 조회를 생략하는 것이다.

**검증**: 모바일에서 기존 OP체크 카드 체크 토글 → `SELECT id, patient_name FROM op_patient_checks WHERE schedule_post_id=…` 로 **id 와 환자명이 유지되는지**. (같은 형태가 `education_completions` 에도 있다.)

## 4. 사용자가 직접 결정·수행해야 하는 것

1. **퇴사자 15명의 비밀번호** — 코드 수정(TB1)과 별개로 지금 비우면 즉시 닫힌다. 다만 재입사·오조작 가능성이 있어 인사 판단이 필요하다. 3명(반민정·윤연이·유채림)은 강제 로그아웃 이후 접속 정황이 있어 **무엇을 열람했는지 확인이 필요할 수 있다** — 로그인 감사 로그가 없어 지금은 추적 불가다.
2. **이미 생성된 오탐 결근 133행** — 급여 일할공제와 월 만근 연차에 이미 들어갔다. 어느 행이 진짜 결근인지는 **급여·인사 담당자만 판정할 수 있다.** 소급 정정 범위를 정해 주면 그에 맞춰 진행한다.
3. **`d1_migrations` baseline 결정** — 현재 상태를 기준선으로 삼을지, 전체를 재정렬할지는 운영 판단이다. 잘못 고르면 전체 재적용 사고가 난다.
4. **Gemini 국외전송(`D10-DS-03`)** — 수술상담 녹음·퇴원심사 환자정보가 동의·비식별 없이 전송되고, **프롬프트가 주민번호를 그대로 포함하라고 지시**한다. 개인정보보호법 판단이 필요해 기술 결함과 분리했다. 법무·원무 확인 후 방향을 정해 주기 바란다.
5. **이미 덮어써진 계약 서명본** — TB12 는 앞으로를 막을 뿐 과거 소실분은 복구되지 않는다. 피해 범위 확인이 필요하다.
6. **`npm run test:e2e:install`** — 모바일 브라우저가 없어 E2E 46스펙이 스킵됐다. 확정 결함의 상당수가 모바일인데 그 게이트가 비어 있다.

> 9차 §4 의 미결 항목도 아직 열려 있다: **`deploy.yml` 품질 게이트** — `needs` 가 없어 **테스트가 깨져도 배포된다.**

## 5. 승인 대상 아님

- **PLAUSIBLE 24건** — 코드 사실은 확인됐으나 발현이 런타임·데이터에 달려 확정하지 못했다. **고치기 전에 확인이 먼저다.** 목록은 [`_data/findings.json`](_data/findings.json) 에서 `verdict:"PLAUSIBLE"`.
- **REFUTED 28건** — 검증자가 반증에 성공했다. 삭제하지 않고 원자료에 남겨 뒀다 — 다음 조사에서 같은 오탐을 반복하지 않기 위해서다. 그중 다수는 "코드 사실은 맞지만 **운영에 데이터 조건이 없어 지금은 안 터진다**"(`TZ-07`·`TZ-08`·`CRON-08`·`M06`·`R01`·`R03`) 이므로, **권한 배치나 데이터가 바뀌면 되살아난다.**
