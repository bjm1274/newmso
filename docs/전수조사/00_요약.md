## 🔴🔴 전체 조사 최우선 (Critical/높음 우선순위)

1. **[Critical 권한상승]** ⑨ `staff_members`가 `PUBLIC_ALL` 정책 + `/api/d1/mutate`가 로그인만 검사 → **일반 직원이 콘솔에서 자기 role을 admin으로 변경 가능**. 즉시 차단 필요. (09_관리자 [SEC-CRITICAL])
2. **[보안]** ③ 가상계좌 웹훅 시크릿 토큰 평문 하드코딩(브라우저 번들 노출), ⑦ 주민번호 평문 감사로그·증명서 권한 부재·계약 PII 평문 저장, ⑨ 데이터초기화 클라 가드만, ② 서류제출 stored XSS, ⑤ 익명소리함 서버 미필터, ⑧ 납품확인서 XSS.
3. **[데이터 정합성/무음 불능]** D1 스키마 드리프트로 다수 기능이 조용히 작동 안 함(아래 패턴). 특히 모바일.
4. **[재무 위험]** ⑦ 급여 계산 SSOT 위반(upsert 덮어쓰기·세금표 4중·국민연금 상하한 누락), ⑧ 재고이관 비원자적(재고 증발).
5. **[죽은 코드 ~18,000줄+]** 미완 리팩토링 잔재 일괄 정리 가능(아래).

## 메뉴 횡단 핵심 이슈 (누적)

- **D1 컷오버 후 테이블/컬럼 정본 불일치 (반복 패턴)**: 여러 화면이 마이그레이션 전 Supabase 스키마 기준으로 작성됨. 확인된 사례:
  - `notifications`: 정본 `user_id`/`read_at`만 ([lib/db/schema.ts:1299](../../lib/db/schema.ts:1299)). 코드 곳곳에서 `is_read`/`read`/`staff_id`/`message`(→`body`) 사용. (① [S-1], ② [S-1][S-2])
  - `approval_documents` 테이블 미존재(정본 `approvals`). (② [S-1])
  - `attendance` ↔ `attendances` 별개 테이블 혼용. (② [S-3])
  - → **메뉴 진행하며 동일 패턴 누적 추적 중. 마지막에 일괄 정리 권장.**
- **데스크톱 ↔ 모바일 도메인 로직 복제**: 할일/서류제출/출퇴근/급여명세서/OP체크/퇴원심사/인계노트/마감보고/직원평가/입금이 데스크톱·모바일에 각각 재구현되어 정책 불일치·정합성 갭 발생. **모바일 측은 옛 Supabase 스키마 기준이라 미존재 테이블/컬럼 쿼리 → 무음 기능불능 다발**. (②③ D/Q/S 다수)
- **🔴 보안 미해결**: 가상계좌 웹훅 시크릿 토큰 평문 하드코딩(③ 입금실시간조회.tsx:661, 번들 노출), 퇴원심사 환자 PII 회사 격리 부재(③). 외부링크 사내 IP/HTTP 하드코딩.
- **미존재 테이블 참조**: `approval_documents`, `op_consultations`, `daily_reports` — 모두 D1 스키마에 없음. 레거시 `chat_messages`(file 컬럼 없음)에 모바일 오프라인 첨부 insert(④).
- **미완 리팩토링 죽은 코드 대량 (전역 최대 이슈)**: ⑦ 인사관리 ~12,000줄(roster 63파일+엔진, 구성원현황 그림자 3229, 조직도그림 1212, 근태뷰 1822, 급여 스텁 등). ④ 채팅 ~4,600줄. ③ OP체크 ~948줄. ⑤ Guide 3종. ⑥ AttendanceCorrection ~500줄. **공통 패턴: 모듈화 신버전이 webpack 파일우선에 가려지거나(구성원현황/index, 메신저메시지조회훅), 진입 컴포넌트 삭제로 클러스터 전체 고아(roster).**
- **급여 계산 SSOT 위반(재무 위험)**: ⑦ payroll_records upsert 헬퍼 미사용(덮어쓰기 위험), 소득세 누진세표 4중 하드코딩, 4대보험 계산식 복붙(중간정산 국민연금 상하한 누락), 비과세 한도 2중정의, 연차 사용일수 연도클리핑 누락 과다계산.
- **레거시 Supabase 스택 잔존 API**: ⑥ `app/api/approval/recall/route.ts`가 `@supabase/supabase-js createClient` + `SUPABASE_SERVICE_ROLE_KEY` 사용 → D1 컷오버 후 실패. (다른 API 라우트도 점검 권장)
- **추가 미존재 테이블**: `board_post_stars`(⑤), `approval_attachments`(⑥), `op_consultations`·`daily_reports`(③), `generated_contracts`·`congratulations_condolences`·`early_leave_records`·`org_chart_nodes`·`licenses`(→staff_licenses)·`staff_appointments`(→personnel_appointments)·`attendance_adjustments`(→attendance_corrections)(⑦), `inventory_transactions`(→inventory_logs)·`as_repair_records`·`return_records`(⑧), `message_templates`·`external_integrations`(⑨). 컬럼 오류 다수(`inventory_logs.amount`→quantity, `notifications.staff_id`→user_id, `audit_logs.severity` 부재 등).
- **escapeHtml 3~4중 정의**: 전자결재-utils / document-print-utils / certificate-print-utils / (+사고보고서 inline).
- **레거시 Postgres 에러코드 분기**: D1 환경인데 `42P01`/`PGRST205` 문자열 매칭(⑤⑨ 등) — 도달 불가.
