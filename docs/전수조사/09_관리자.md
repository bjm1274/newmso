## 🔴🔴 최우선 — Critical 보안 (✅ 확인, 전체 조사 최고 심각도)

### [SEC-CRITICAL] 권한 상승(Privilege Escalation) — 일반 직원이 관리자 승격 가능
- **위치**: `lib/db/auth/policies.ts:115 staff_members: PUBLIC_ALL` + `app/api/d1/mutate/route.ts:236` + `직원권한통합.tsx:123 updateStaffRecord`
- **확인**: `staff_members` 정책이 `PUBLIC_ALL`(select/insert/update/delete 전부 PUBLIC). `/api/d1/mutate`는 **로그인 여부만 검사**(`userId(session?.user)`)하고 테이블별 인가(assertAccess)도 PUBLIC이라 통과. → 일반 직원이 브라우저 콘솔에서 `supabase.from('staff_members').update({ role:'admin', permissions:{ system_master:true } }).eq('id', 본인)` 직접 호출로 **관리자 승격 가능**. 권한 UI 게이트(`hasSystemMasterPermission`)는 화면 숨김일 뿐 서버 인가 없음.
- **부가**: 자기 자신 권한 자가 상향 가드 없음. 메시지 삭제도 PUBLIC `messages` 직삭(`시스템마스터센터.tsx:1350`)으로 임의 사용자 삭제 가능. 감사로그가 클라이언트 작성(actor 위변조 가능).
- **조치(즉시)**: `staff_members`의 update/delete 정책을 admin/mso 한정으로 좁히거나, role/permissions 변경을 **인가 검증 포함 전용 서버 라우트**로 분리. 자가 권한상향 차단.
