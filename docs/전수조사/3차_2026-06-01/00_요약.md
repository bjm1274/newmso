## 🟠 구조적 패턴 (3대 이슈)

### 1. 워크센터 ↔ 레거시 전면 병행 (최대 구조 이슈)
새 "워크센터" UI가 레거시 컴포넌트를 재사용하지 않고 재구현 → 동일 도메인 2경로 + 워크센터는 골격(무동작 버튼)·실기능은 레거시:
- **인사관리**: payroll `Mod*13` = 레거시 급여명세 재구현(계산 lib만 공유) + 무동작 버튼 다수. Leave/Member/Attend/Docs 워크센터 ↔ 레거시 병행.
- **재고관리**: Status/Item/IO/Analyze 워크센터 ↔ 재고관리서브 15+화면 재구현. **무동작 버튼 12개+**, 월마감/실사 더미.
- **관리자**: ExecDashboard 등 `관리자워크센터/`(모바일 래핑) ↔ `관리자전용서브/` 레거시. ExecDashboard `staffs=[]/user=null` degrade.

### 2. 모바일 하드코딩 더미 / 무동작 UI
- **재고**: Hub KPI(847종/23건)·분석마감·발주/자산등록 대량 더미(주석도 인정).
- **관리자**: 허브 매출 182,420,000원·"요청 2"·실명 "정서운"(경영대시보드).
- 전 메뉴 모바일에 **onClick 없는 장식 버튼**(검색/더보기/필터/입출고/발주 등) 다수.
- (단, 알림탭·내정보·추가기능 모바일은 실 fetch로 **수정됨** — 위 정정 참조.)

### 3. 전역 중복 (메뉴 횡단)
- `KpiCard` 동명 5~7곳 · `PermissionDiffPanel` 동명 2개 · `MIME_BY_EXTENSION` 3중(채팅/게시판/api) · `SCHEDULE_META`+`extractScheduleMetaFromContent` 3중(OP체크/게시판) · `getKoreanTodayString` 3중 · `insertChatMessageWithFallback` 2벌 · 게시판공통↔view-utils 28심볼.
