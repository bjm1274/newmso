### [S-1] 경조사관리 — 존재하지 않는 테이블 `congratulations_condolences` + 실패 은폐 폴백
`인사관리서브/경조사관리.tsx:112` (조회), `:134-140` (insert+폴백)
```ts

...
```

- 조치: 테이블 마이그레이션 생성 후 폴백 제거하고 정상 에러 토스트로 교체.

2. **★특별임무 검증 결과**:
   - 증명서/문서/print-utils 중복 → escapeHtml 4중(+inline 1) / getClosingText·formatDate 중복 **확인**. getClosingText는 내용까지 divergence.
   - 근태 3종(통합/조기/지각) 중복 → **기각**. 통합분석은 단순 래퍼, 로직 중복 없음.
   - 4대보험 vs 급여명세/EDI 중복 → 4대보험관리는 `insurance_records` 신고 이력 관리로 EDI 파일 생성(`원천징수파일생성`/`4대보험EDI`)과 **역할 분리됨**. 데이터 중복 아님.
3. **보안**: 발급 증명서(급여 PII 포함) 열람에 권한 검증 부재(SEC-1), 사고/의료기기 회사 격리 부재(SEC-2/3).
