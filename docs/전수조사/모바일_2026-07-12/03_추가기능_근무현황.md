## Critical — 근무현황

### W-C1. 미출근 전원 「근무중」

```ts
// data-hooks.ts useWorkNow
if (state === 'unknown') state = 'working'; // 치명
```

- PC: check_in 있고 check_out 없을 때만 근무중 (`근무현황.tsx:525–528`)

### W-C2. status vs current_status 오판

- `attendances.status` 기본값 `present` (일 단위 근태)
- 실시간: `current_status` (break/lunch/field)
- `deriveState`가 present를 모름 → unknown → C1으로 working

### W-C3. 테이블 불일치

| 경로 | 테이블 |
|------|--------|
| 모바일 체크인 | `attendance` (date, check_in, current_status) |
| 모바일 근무현황 | `attendances` only (work_date, …) |
| PC 근무현황 | **둘 다 merge** |

→ 모바일에서 찍은 출근이 근무현황에 안 잡히거나 전원이 오표시.

### 권장 판정 로직 (PC 정렬)

1. 체크인 없음 → 미출근  
2. 체크아웃 있음 → 퇴근  
3. 그 외 current_status: break/lunch→휴게, field→외근, null→근무중  
4. present/late는 일 근태 라벨, 실시간 상태 아님
