## 3. 영역별 딥 요약

### 3.1 스크롤 아키텍처

```
.mso-mobile fixed overflow:hidden
  .m-screen overflow:hidden height:100%
    header (sticky 무의미 — 형제 고정)
    .m-scroll flex:1 overflow-y:auto  ← 유일한 스크롤 (min-height:0 필수!)
    m-sticky-foot
  MobileBottomTab fixed z:999 h:64 bottom:16
```

**신규 핵심:** `.m-scroll`에 `min-height:0`이 없어 flex 아이템이 줄어들지 않고, 기기/브라우저에 따라 **스크롤이 안 생기는** 전역 리스크 (S0).

**padding 덮어쓰기 전수 (88px 무력화)**

| 파일 | 패턴 |
|------|------|
| 내정보/홈, 출퇴근, 연차, 정보수정, 증명서 | `paddingBottom: 24` |
| 내정보/급여명세 | `padding: 16px` + `paddingBottom: 24` |
| 게시판목록 홈 | `padding: 12px 0 24px` |
| 추가기능/허브, 외부웹팩스, 직원평가 | `padding: … 24px` |
| 채팅방 리스트 | `padding: 12px 12px 6px` (탭 숨김 전제) |

### 3.2 z-index 스택 (확정)

| z | 레이어 | 판정 |
|---|--------|------|
| 1 | .mso-mobile | — |
| 40 | msm-subscreen | 탭 아래 |
| **50** | 비번 모달, 복지/징계 z-50 | **탭에 가림** |
| **60** | msm-pw-scrim CSS, 이모지 피커 | **탭에 가림**(채팅은 탭 숨김) |
| 99 | sticky 헤더 | — |
| **200** | 계약 전자서명 | **탭에 가림** |
| 200–201 | 오프라인 배너 | OK |
| **300** | 퀵메뉴 편집 | **탭에 가림** |
| **999** | 플로팅 탭 | 기준 |
| 1000 | 오프라인 실패 시트 | 경계 |
| 1500 | MSheet | OK |
| 9999 | HR 일부 모달, PTR | OK |
