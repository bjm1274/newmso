## 4. 공통 안티패턴

1. **Silent failure** — `error` 미검사 / catch 빈 블록 → 빈 화면 = 데이터 없음으로 위장  
2. **가짜 성공 UI** — toast만 하고 실제 API/업로드 없음 (PDF, 권고 발송, 승인 요청)  
3. **PC 패리티 붕괴** — 테이블명(`attendance` vs `attendances`), 상태 필드(`current_status`), 병합 로직 미이식  
4. **전역 네비 오염** — `subView='전체'`가 모바일 게시판 필터에 누수  
5. **데모/하드코딩** — 발주 기본 품목, 회사 폴백 `'박철홍정형외과'`, demo R2 URL  
6. **권한 게이트 부재** — 관리자 탭만 차단, 인사·재고 탭은 항상 노출
