## Critical — 「글이 안 보여요」 원인

### B-C1. 전역 subView='전체' → cat=free (최우선)

```
page.tsx: subView 초기값 '전체'
  → 게시판 index: if (subView) view='list', cat=boardTypeToCat('전체')
  → boardTypeToCat 매칭 실패 → 'free'
  → 자유게시판만 필터. 공지/경조사 등 전부 숨김
```

- **파일:** `app/main/page.tsx:125`, `게시판/index.tsx:47–68`, `data-hooks.ts:67–69`
- **수정:**
  1. 게시판 subView 화이트리스트 (BoardCatId / BOARD_IDS 만)
  2. 그 외 → view=`home`, cat=`all`
  3. `boardTypeToCat` unknown 폴백을 `'free'` 대신 `'all'` 또는 null

### B-C2. 쿼리 에러 무시

```ts
const { data } = await withMissingColumnsFallback(...);
// error 미검사 → data null → []
```

- **파일:** `data-hooks.ts:96–116` (목록), `210–227` (상세)
- **수정:** `if (error) toast(...); return;`

### B-C3. poll / poll_votes / is_anonymous 가 REQUIRED

- OPTIONAL omit fallback 불가. 컬럼 없으면 전체 select 실패 → C2와 결합 시 빈 목록.
- **수정:** OPTIONAL로 이동 또는 마이그레이션 강제.

### B-C4. overridePosts 가 refetch 가로챔

- `posts = overridePosts ?? fetched`
- 좋아요/삭제 후 override 고정 → PTR·작성 후 서버 목록 미반영
- **수정:** refetch 성공 시 `setOverridePosts(null)`
