## 조사 발견

### P0 후보
- **AU-01** 세션 HMAC 폴백 시크릿이 소스에 하드코딩. Edge 미들웨어는 env가 있어도 **레거시 키를 두 번째로 검증**. 저장소 문자열로 `/main` 쿠키 위조 가능.

### P1 후보
- **AU-02** 미들웨어는 서명만. 재직·강제로그아웃 DB 없음. `/main` 셸은 session API까지 살아 있음.
- **AU-03** `퇴사예정`은 재로그인·기존 세션 모두 통과. 슬라이딩 세션이 30일을 재발급.
- **AU-04** Oracle vs CF 크론 시각이 다름. `verify-cron-wiring`은 `server.mjs`를 안 봄.
- **AU-05** todo-reminders / auto-report는 스케줄 없음.
- **AU-06** 급여일·면허·계약·연차소멸 인앱 INSERT는 푸시 팬아웃 없음.
- **AU-07** 야간 22–08 푸시 금지 + Oracle cleanup 03:00이 인앱 푸시를 삼킴. 아침 재푸시 타입이 좁음.

### P2
