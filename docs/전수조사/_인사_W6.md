### 2-1. 휴가관리메인.tsx(647) 단일책임

### 2-2. 연차 계산 로직 중복 (D) — 최우선

## 3. 발견 상세 (파일:줄 + 코드인용)

### ▣ 휴가관리메인.tsx

#### D-1 [높음] 연차 사용일수 reduce 3중 복제 + 정본 헬퍼 미사용
`handleStatusUpdate`(L197-213), `handleEditLeave`(L284-300), `handleDeleteLeave`(L369-385) 에 **완전 동일한 reduce 블록**이 복붙됨:
```ts
// L197-213 (handleStatusUpdate) — L284-300, L369-385과 동일
const approvedAnnualLeaveDays = staffLeaves.reduce((sum, row) => {
  const isApproved = (row.status as any) === '승인' || (row.status as any) === 'approved';
  if (!isApproved) return sum;
  const type = String(row.leave_type || '').trim().toLowerCase();
  const isHalf = type === 'half_leave' || ... || type === '오후반차';
  if (isHalf) return sum + 0.5;
  const isAnnual = ... || type.includes('연차');
  if (!isAnnual) return sum;
  const start = new Date(row.start_date);
  const end = new Date(row.end_date || row.start_date);
  const diffTime = Math.abs(end.getTime() - start.getTime());
  const diffDays = Math.ceil(diffTime / (1000*60*60*24)) + 1;
  return sum + diffDays;
}, 0);
```
- 정본 `calculateApprovedAnnualLeaveUsage(rows, year)` 가 동일 로직을 이미 제공하며, 의존하는 `seoul-time.ts`에 D1 import 없음(브라우저 안전 — Grep 확인) → **3블록 모두 `calculateApprovedAnnualLeaveUsage(staffLeaves)` 한 줄로 대체 가능.**
- L193 주석("client-side to prevent D1 server-only binding error")은 오해: 정본 *계산* 헬퍼는 D1을 쓰지 않음. D1을 쓰는 건 `syncAnnualLeaveUsedForStaff`뿐.

#### D-2/S-1 [높음] 인라인 계산이 정본과 결과 불일치 (year-clipping 누락)
- 정본 `calculateApprovedAnnualLeaveUsage`는 `clipDateRangeToYear`로 **해당 연도 구간만** 합산.
- 인라인 버전(L208-212 등)은 연도 클리핑 없이 전체 기간을 합산 → **연말~연초 걸친 휴가나 다년 데이터에서 사용일수 과다 계산**. 같은 직원의 used_days가 어느 핸들러를 거치느냐(`window`면 인라인, 서버면 `syncAnnualLeaveUsedForStaff`)에 따라 **달라질 수 있음**.
- 추가: 인라인은 `Math.abs(end-start)`(방향 무시)인데 정본 `calculateLeaveDays`는 `end-start`(음수면 `Math.max(1, …)`로 보정). end<start 비정상 입력 시 동작 상이.

#### T-1 [중간] `leaves` 상태가 `any[]`로 흘러감
L106 `let list: any[] = data || [];`, L194/281/367 `leaves.map(...)` 결과를 `any`로 다룸. `Leave` 타입이 있으나 페칭·reduce 경로에서 `any` 캐스팅 남발(L198 `row.status as any`).

#### T-2 [낮음] 컴포넌트 props가 `Record<string, unknown>`
L70 `}: Record<string, unknown>)` — `staffs`, `selectedCo`, `user` 등 전부 unknown으로 받아 본문에서 `as` 캐스팅 반복(L78, L128, L446 등). props 인터페이스 정의 권장.

#### S-2 [중간] 연차 자동부여 근속연수 계산 부정확
L449 `years = (now - join) / (365.25*24*60*60*1000)` 후 L459 `15 + Math.floor((years-1)/2)`.
- 근로기준법은 "회계연도/입사일 경과 연차(정수 근속연수)" 기준인데 소수 근속연수(365.25 평균)로 floor → 윤년·경계일에서 1년 오차 가능. (회계연도 분기 L454는 `getFullYear()` 차이로 별도 계산 — 두 분기 로직 비대칭.)

#### E-1 [낮음] catch에서 err 미사용·미로깅
L251 `catch (err) { toast('처리에 실패했습니다.', 'error'); }` — `console.error` 없음. handleEdit(L339), handleDelete(L418)도 동일. 실패 원인 추적 불가.

#### U-1 [낮음] 미사용 import `STORAGE_KEYS` 외 — 확인결과 사용됨(L164). 해당 없음 처리.
