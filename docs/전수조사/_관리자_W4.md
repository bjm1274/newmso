## ★ 미존재 테이블/컬럼/API (무음 기능불능) — 최우선

확인된 D1 정본 사실:
- `audit_logs` 컬럼 = `id, user_id, user_name, action, target_type, target_id, details, ip_address, created_at, actor_name` (schema.ts:201-215). **`severity`, `title`, `target` 컬럼 없음.**
- D1 정본에 **`message_templates` 테이블 없음**, **`external_integrations` 테이블 없음** (schema.ts 전체 grep 무결과, policies.ts 미등록).
- `app/api/admin/audit/` 디렉터리 부재 → **`/api/admin/audit/summary` 라우트 없음** (app/api/admin/*는 notifications/reset-staff/verify-unlock/seal/popups/annual-leave/staff-password/force-logout/system-master 만 존재).

### ①  audit_logs 미존재 컬럼 쿼리 — `data-hooks.ts:140-146` (`useAuditLogs`)
```ts
let q = supabase
  .from('audit_logs')
  .select('id, severity, title, actor_name, target, created_at, company')  // severity/title/target 미존재
```
`audit_logs`에는 `severity`/`title`/`target` 컬럼이 없고 `company` 컬럼도 없음(있는 건 `actor_name` 뿐). `company` 필터(`q.eq('company', company)`)도 미존재 컬럼 → SQL 에러 → `catch{}`(168행) → `source='fallback'` → **감사 로그 탭이 항상 "샘플 표시"(빈 목록)**. 사용처: `감사백업.tsx:150 LogTab`.
정정 방향: `select('id, action, target_type, target_id, details, user_name, created_at')` + severity는 action/details 기반 클라 추론, 회사필터 제거 또는 user_id 매핑.

### ②  message_templates 테이블 미존재 — `운영설정.tsx:184-188` + `data-hooks.ts:360-363`
```ts
// 운영설정.tsx useMessages
.from('message_templates').select('id, name, channel, send_count, status, template_group')
// data-hooks.ts toggleMessageTemplateStatus
.from('message_templates').update({ status: after, ... }).eq('id', templateId)
```
테이블 자체가 D1·policies.ts에 없음 → 읽기는 catch→FALLBACK_MSG(9종 mock) 항상 표시. 토글은 mutate 라우트 `ALLOWED_TABLES` 거부(403) → 낙관적 업데이트 후 롤백 + 오류 toast. **메시지 12종 탭은 영구 mock**(다만 `isRemote:false`라 토글 버튼은 애초 비노출되어 사용자 혼란은 작음).

### ③  external_integrations 테이블 미존재 — `운영설정.tsx:450-454` (`useIntegrationData`)
```ts
.from('external_integrations').select('id, vendor, name, sub, status, last_synced_label')
```
테이블 없음 → catch → FALLBACK_INT(6종 mock) 항상 표시. **외부연동 6 탭은 영구 mock(read-only라 기능손상은 표시 오인 수준).**

### ④  /api/admin/audit/summary 라우트 미존재 — `data-hooks.ts:67` (`useAuditSummary`)
```ts
const res = await fetch('/api/admin/audit/summary', { cache: 'no-store' });
if (!res.ok) throw new Error(`HTTP ${res.status}`);  // 404 → throw → catch → FALLBACK
```
라우트 부재 → 404 → 폴백(전부 0). **감사백업 상단 4 KPI(오늘로그/이상감지/급여이상치/백업시간)가 항상 0/0/0/0** 표시. 게다가 안내 칩에 "백업 1시간 전" 등은 시스템마스터의 정적 mock(시스템마스터.tsx:250-255)과 불일치.
