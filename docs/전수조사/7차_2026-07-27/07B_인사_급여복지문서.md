# 07B. 인사관리 — 급여·복지·계약문서 전수조사 (7차, 2026-07-27)

## 요약

- 급여 13모듈은 **UI 껍데기가 아니다** — 4대보험·최저임금·통상임금·퇴직금·비과세 모두 실제 계산 코드가 존재하고 대부분 실 DB(`payroll_records`, `staff_members`)를 읽는다. 다만 `payroll-fetch.ts:217`이 **DB 스키마에 없는 컬럼(`agreed_overtime_allowance`, `agreed_night_allowance`)을 select** 하고 있어, 이 쿼리가 SQL 오류로 떨어지면 13개 모듈 전부가 빈 데이터로 표시된다(A8-01, P0).
- 급여 조회는 서버 정책(`lib/db/auth/policies.ts:562`)으로 `payroll_records = SELF_OR_SAME_COMPANY`가 걸려 있어 `/api/d1/query` 우회로 타사 급여를 긁는 경로는 확인되지 않았다. **급여 권한 자체는 서버에서 지켜진다.** 반면 `contract_templates`가 `PUBLIC_ALL`(policies.ts:411)이라 **로그인한 아무 직원이나 근로계약서 본문과 직인 URL을 바꿔 쓸 수 있다**(A8-02, P0).
- `document_repository` / `certificate_issuances`가 **ADMIN_ONLY**로 잠겨 있어(policies.ts:795·837 → 892-897), 관리자가 아닌 직원이 근로계약서에 전자서명하면 문서보관함 저장이 403 → throw → **서명 자체가 저장되지 않는다**(A8-03, P0). 같은 이유로 증명서 발급 이력도 남지 않고, `hr_문서보관함` 권한자도 목록이 비어 보인다.
- 알림은 **급여명세서 도착·계약 만료·면허 만료·서명 요청 전부 in-app row만 들어가고 웹푸시가 나가지 않는다.** 미지급수당·건강검진은 알림 row조차 없고, 서류 제출 독촉 버튼은 토스트만 띄우는 완전 no-op다(A8-09 ~ A8-12).
- PC↔모바일: 급여 13모듈은 동일 컴포넌트 재사용으로 100% 대응. 복지는 달력 탭·KPI·만료보드가 미이식, 문서는 계약서 자동생성이 stub이다.

2. **`전자서명모달.tsx`(52k, 1000+줄) 전문** — 서명 캔버스 → `onSuccess(signatureData, fullContractHTML, receiptTraceData, privacyConsent)`(:565) 콜백까지만 추적했다. 서명 이미지가 base64 data URL로 `employment_contracts.signature_data` TEXT 컬럼에 그대로 저장되며 R2를 쓰지 않는다는 점(마이페이지/index.tsx:297)은 확인했으나, 모달 내부의 동의 항목·비밀유지서약서 렌더 정합성은 미확인.
3. **`급여정산.tsx`(82k)** — `calculateMonthlyIncomeTax` 사용(:1108-1114)과 `upsertPayrollRecordsWithFallback` 저장(:1252, :1354)까지만 확인. 수당 산정·근태 연동 상세 로직은 미확인(A8 범위상 급여 워크센터 진입 경로 위주로 조사).
4. **R2 객체 키 획득 가능성** (A8-14) — ACL 부재는 확인했으나, 키가 실제로 어떤 테이블·API를 통해 타인에게 노출되는지는 미검증.
5. **`mutate` 소유권 스푸핑** — `app/api/d1/mutate/route.ts:215-267`의 `enrichRowProxyForPolicy`가 `where.id eq`가 있을 때만 DB 정본으로 덮어쓴다(:239-240). `id` 없이 다른 컬럼 조건으로 UPDATE할 때 `employmentContractUpdateGuard`(policies.ts:189-198)의 `staffId === null` 통과 분기를 탈 수 있는 코드 경로는 확인했으나, 실제 악용 가능 여부는 미검증.
6. **`notification-repush` 실효성** — `lib/notification-repush.ts`의 limit 상한과 실패 재시도 정책 미확인.
7. **비과세 야간수당 연/월 단위** (A8-25) — 정산 코드에서 이 상수가 월 단위로 차감되는지 끝까지 추적하지 못함.
