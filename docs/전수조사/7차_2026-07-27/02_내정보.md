# 02. 내정보(마이페이지) 전수조사 (7차, 2026-07-27)

## 요약

PC(`app/main/기능부품/마이페이지/index.tsx`) 7개 탭 + 모바일(`app/main/모바일/내정보/`) 7개 서브뷰를 전부 코드 추적했다.
가장 심각한 문제는 개별 화면이 아니라 **D1 정책 레이어**다. `lib/db/auth/policies.ts:892-897` 이 `ADDITIONAL_PUBLIC_TABLES` 전체를 `ADMIN_ONLY_ALL` 로 덮어쓰면서, 내정보가 쓰는 `todos` / `document_repository` / `certificate_issuances` / `audit_logs` 4개 테이블이 관리자 전용이 되었다. 결과적으로 **일반 직원 기준 할일·서류제출·증명서·정보수정 4개 기능이 조회 0건 + 저장 403 으로 완전 불능**이며, 근로계약서 전자서명까지 연쇄 실패한다(P0 4건).
권한 면에서는 `/api/annual-leave/summary` 가 `staffId` 를 쿼리스트링으로 그대로 받아 세션 대조 없이 원장을 반환하는 IDOR 가 확인됐다(P0 1건).
PC↔모바일 불일치는 퇴사자 게이트(모바일 무방비), 정보수정 본인확인(모바일 없음), 모바일 서류제출 전자서명 버튼 도달 불가가 핵심이다.
알림 측면에서는 이 메뉴에서 발생해야 할 알림(할일 리마인더·계약서 서명완료·증명서 발급·급여명세서 도착) 중 **푸시까지 도달하는 경로가 0건**이다.
