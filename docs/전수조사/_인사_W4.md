## [X] 죽은코드

`근무표자동편성-engine-coverage.ts:426-470` — while 루프 안에서 `blockedBandDates`/`blockedWeekdayDates`/`weekendDates`/`holidayDates`/`restrictionFragments`/`items`/`row` 를 빈 배열·빈 객체로 선언 후, 절대 채워지지 않는 조건문으로 `items.push(...)`. `items`는 어디에도 반환/사용되지 않음. 루프마다 재실행되는 순수 죽은코드(=불필요 연산). 인용:
```
const items: Array<{...}> = [];
const row = { staff: { id: '', name: '' } };
if (blockedBandDates.length > 0) { ... }   // 항상 false
...
if (restrictionFragments.length > 0) { items.push({ id: `restriction-${row.staff.id}`, ... }); }
```
복사-실패 흔적으로 보이며 즉시 삭제 가능.
