## D. 중복

### D-1 [높음] 메타 조회 로직이 통합 함수와 개별 refresh 함수에 통째로 중복
`syncVisibleMessageMetadata` 안의 리액션 집계(메신저메시지조회훅.ts:461-502), 핀 메시지 처리(521-565), 투표 처리(577-606)가
`refreshVisibleMessageReactions`(708-749), `refreshRoomPinnedMessages`(802-849), `refreshRoomPolls`(868-897)에 거의 그대로 복제됨.
근거: 리액션 reduce/유저맵/정렬 블록이 461-502 과 708-749 에서 동일.
```ts
// 461-470 (sync) 와 716-720 (refresh) 동일 패턴
if (!reactionCounts[messageId]) reactionCounts[messageId] = {};
reactionCounts[messageId][emoji] = (reactionCounts[messageId][emoji] || 0) + 1;
```
조치: 리액션/핀/투표 각각 순수 변환 함수로 추출(예 `buildReactionMaps(rows, resolveStaffProfile)`)해 양쪽에서 호출. 심각도: 높음(유지보수 리스크, ~150줄 중복).

### D-2 [중간] 날짜점프 vs 메시지점프 함수 거의 동일
`loadMessagesAroundDate`(1127-1274)와 `loadMessagesAroundMessage`(1276-1458)가 타깃조회 1건 차이 외에 before/after 조회·merge·enrich·setMessages·syncMeta 흐름이 동일(각 ~150줄).
근거: 1183-1248 과 1366-1431 블록이 변수명만 다르고 동일.
조치: 공통 `loadAround(targetMessage, roomIds, ...)` 추출 후 타깃 조회만 분기. 심각도: 중간.

### D-3 [낮음] is_deleted 필터 분기 불일치(중복 의도지만 다름)
`useChatArchiveMessages.ts:93-95`는 `omittedColumns.has('is_deleted')` 가드 후 `.eq('is_deleted', false)`,
`메신저데이터유틸.ts:95`는 가드 없이 `.eq('is_deleted', false)`. 동일 의도 필터가 두 방식으로 산재.
조치: 공통 헬퍼로 통일. 심각도: 낮음.

> 특별임무 결론: chatQueryService.ts는 **메시지 조회가 아니라 chat_rooms 조회** 전담이므로 메시지조회훅과 직접 중복 아님. 실제 메시지조회 중복은 (a) 훅 내부 D-1/D-2, (b) 훅 vs useChatArchiveMessages의 messages.select 패턴(둘 다 `selectChatMessagesWithFallback` 공유하므로 select 절 자체는 비중복). 유틸 3개 함수 중복은 아래 X/Q 참조 — 실제 동일구현 중복은 없음(`haveSameMembers` vs `arraysMatch`는 정렬 유무로 의미 상이).

## P. 성능

### P-1 [중간] 답글 미리보기 매 렌더 O(n) 선형탐색
`메신저타임라인.tsx:721` `messages.find((m) => m.id === msg.reply_to_id)` — 타임라인 map 내부에서 reply 메시지마다 전체 messages 배열 스캔. 답글 많은 방에서 O(n²).
조치: 상위에서 `Map<id,message>` 1회 생성해 props로 전달 또는 useMemo. 심각도: 중간.

### P-2 [낮음] useEffect/useLayoutEffect 의존성 누락(주로 ref라 안전)
- `useChatArchiveMessages.ts:136` deps `[archiveRoomIdsKey]` 인데 본문은 `archiveRoomIds`·`selectChatMessagesWithFallback` 사용. key가 배열변화에 1:1 대응해 동작상 안전하나 lint 경고·잠재 stale.
- `useChatTimelineScroll.ts:285`(useLayoutEffect),`:338` deps에서 `setShowScrollToLatest`/일부 ref 누락 — 대부분 ref라 무해.
심각도: 낮음.

### P-3 [낮음, 양호] 조회 디듀프 잘 구현됨
`fetchData`(1077) in-flight/큐/30s 최소간격, `fetchAllChatRooms`(chatQueryService.ts:57) 5s TTL+in-flight, 메타 60s TTL 캐시(337) — 중복 API 방지 설계 양호.
