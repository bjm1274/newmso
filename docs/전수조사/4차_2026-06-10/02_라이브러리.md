## MAJOR

### [M-1] d1-compat UpdateBuilder.filter() 연산자 무음 붕괴 (잠재 지뢰) ✅
- 파일: `lib/d1-compat/mutation-builders.ts:147-154`
- `filter(field, op, value)`가 `'eq'`/`'in'` 외 모든 연산자(gte·lte·gt·lt·neq·like…)를 **조용히 `'eq'`로 변환**. 전용 메서드(gte() 등)는 정상이나 filter() 경로는 오류도 던지지 않음.
- ✅현재 non-eq/in으로 filter()를 호출하는 코드 0곳 grep 확인 → critical 아님. 단 향후 사용 시 무음 데이터 오염이므로 미지원 연산자는 throw하도록 수정 필요.

### [M-2] Drizzle sql 태그에 JS 배열 직접 IN 바인딩 ✅
- 파일: `lib/notification-utils.ts:272-276`
- `sql\`... user_id IN ${adminUserIds} AND type IN ${alertTypes}\`` — Drizzle sql 태그는 배열을 IN 목록으로 전개하지 않음. D1 바인딩 타입 제약상 런타임 실패 가능성 높고, **감싼 try/catch가 삼키면 중복 알림 dedupe가 무력화**되어 관리자 중복 알림 발송. `inArray()`로 교체.

### [M-3] D1 미지원 `db.transaction()` 사용 — 재고 원자성 미보장
- 파일: `lib/db/functions/inventory.ts:106(atomicStockTransfer), 205(atomicStockConsumeWithLog)`
- Cloudflare D1은 인터랙티브 트랜잭션 미지원. 타입은 통과하나 런타임 오류 또는 비원자 실행 위험. `atomicStockUpdate`는 단일 UPDATE RETURNING으로 올바름 — 동일 패턴(batch())로 통일 필요. (3차 "재고이관 원자성"은 API 경유로 수정됐으나 이 lib 함수 경로가 잔존)

### [M-4] polling-bus 타이머 2종 영구 누수
- 파일: `lib/polling-bus.ts:134(핑 하트비트), 183(idleCheckTimer)`
- 모듈 로드 시/최초 호출 시 생성되는 setInterval이 변수 미보관·해제 메커니즘 없음. 탭 수명 동안 영구 실행.

### [M-5] 알림 직접 insert — 푸시 파이프라인 우회
- 파일: `app/main/hooks/useSupplyWorkflow.ts:185, 257, 362`
- `supabase.from('notifications').insert()` 직접 호출 → `dispatchPushForNotificationRows` 미경유 → 앱/탭 닫힘 상태에서 FCM/WebPush 미발송. (push-pipeline 메모리의 "모바일 트리거 누락"과 동일 계열 잔존 사례)

### [M-6] chat-read-cursors N+1
- 파일: `lib/chat-read-cursors.ts:65-95` — 방 수 N에 대해 2N 쿼리. `db.batch()`로 축소 가능.
