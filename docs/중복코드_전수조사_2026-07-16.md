## 0. 한 줄 결론

**기계적 exact-clone 비율(약 3.4%)은 중간 수준**이지만, 진짜 부채는 “비슷한 줄”이 아니라 **PC/모바일·신/구 워크센터·이중 API**에 갈라진 **비즈니스 규칙 이중화**다.  
가장 위험한 축은 **연차 `leave_type` 표기**, **결재함 분류/자동 결재선**, **업로드 한도·라벨 불일치**, **고아 통파일(급여/근태 레거시)** 이다.

| 지표 | 값 |
|------|-----|
| 소스 규모 (app+lib ts/tsx) | ~1,000+ 파일 |
| jscpd exact clones | 476 |
| 중복 라인 / 전체 라인 | 9,902 / 295,768 (**3.35%**) |
| 교차 파일 페어 | 201 |
| 동명 basename 충돌 (의미 있는 것) | ~25종 (route.ts 제외) |
| 분석 트랙 | 4 병렬 + 기계 검출 |

## 2. P0 — 즉시 조치 권장

### 2.1 연차 `leave_type` 표기 체계 3종 이상 (데이터 드리프트)

동일 테이블(`leave_requests` / 결재 payload)에 서로 다른 문자열이 저장된다.

| 진입점 | 저장 값 예 |
|--------|-----------|
| 모바일 인사 `연차신청.tsx` | `연차`, `반차`, `경조사`, `병가` |
| 모바일 결재 `연차신청폼.tsx` | `연차 (1.0)`, `반차 (0.5)` |
| PC `전자결재서브/근태신청양식.tsx` | `DEFAULT_LEAVE_TYPE = '연차 (1.0)'` |
| LeaveWorkcenter `LeaveQuickForm` | `연차`, `오전반차`, `오후반차`, `연차(부여)` 등 |
| 서버 승격 | `includes('반차'/'병가')` 휴리스틱 |

**권장**: `lib/leave-type.ts` 정본 상수 + `normalizeLeaveType()` 호환 레이어 + 기존 값 마이그레이션/매핑. 신청 API/폼은 전부 정규화 후 저장.

### 2.2 결재: 함 분류 · 자동 결재선 · 상신 경로 이중화

| 항목 | PC | 모바일 | 위험 |
|------|----|--------|------|
| 함 분류 | `전자결재.tsx` filter | `결재/data-hooks.ts` `classifyForStaff` | 같은 문서가 다른 함에 표시 |
| 자동 결재선 | `useApprovalRouting` (`APPROVER_POSITIONS`) | `useApproverLine` (부서장 이상 + SY 규칙) | **기본 결재선 불일치** |
| 상신 | `useApprovalSubmit` | `기안상신.ts` + `useApprovalFormBase` | 사이드이펙트 drift |
| 출결정정 | `출결정정양식.tsx` | `출결정정폼.tsx` | jscpd ~117 lines 공유 클론 |

**권장**: `lib/approval-inbox.ts`, `lib/approval-routing.ts` SSOT. 폼 UI만 듀얼.

### 2.3 업로드 정책 불일치 (라벨 ≠ 바이트, 이중 엔드포인트)

| 이슈 | 증거 | 심각도 |
|------|------|--------|
| 서류 한도 라벨 **30MB** vs 바이트 **200MB** | `lib/document-submission-shared.ts` L20–40 (`DOC_MAX_FILE_SIZE_BYTES = 200*1024*1024`, `DOC_MAX_FILE_SIZE_LABEL = '30MB'`) | **P0** |
| 채팅 비이미지 에러 **“20MB”** vs 한도 **200MB** | `app/api/chat/upload/route.ts` L100–102 | **P0** |
| `POST /api/approval/upload` (presign JSON) vs `POST /api/approvals/upload` (multipart direct) | path·검증·storage 경로 불일치 | **P0** |
| board upload 파일 내 null-byte 1개 | `app/api/board/upload/route.ts` (바이너리 오염 의심) | **P0** 점검 |
| board/chat/approval/submission upload 보일러플레이트 | jscpd 다수, `normalizeMime` 로컬 복제 | P1 통합 |

**권장**: `createUploadHandler({ prefix, maxBytes, mimePolicy })` + 상수/라벨 단일 SSOT. `approval`/`approvals` 업로드 중 하나 deprecate.

## 12. 조사 한계

- jscpd는 **토큰 exact clone** 위주 — 의미 동일·이름만 다른 로직은 수동/에이전트 조사로 보완  
- dynamic `import(variable)` 문자열 진입은 100% 보장 못함  
- 고아 판정은 **정적 import 기준** — e2e/즐겨찾기 문자열 경로는 삭제 전 스모크 필요  
- `analysis_artifacts` 내부 해시 복제 파일은 프로덕션 미포함
