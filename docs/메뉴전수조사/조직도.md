# 메뉴 전수조사 보고서 — 조직도

> 조사 대상: `app/main/기능부품/조직도서브/` (5개 파일)
> 특징: 조직도 자체 렌더링 + **전체 앱의 메뉴 라우터·사이드바** 역할을 동시에 수행

## 1. 메뉴 개요

조직도서브는 두 가지 역할을 겸한다.
1. **조직도 화면**(OrgChart): 회사별 직원 트리, 부서/팀 그룹핑, 오늘 근무중 현황.
2. **앱 셸**(조직도본문 + 조직도측면창): 전체 메인 메뉴의 lazy-load 라우터 + 사이드바/모바일 탭바.

## 2. 파일 구성표

| 파일 | 역할 | 핵심 데이터 흐름 |
|------|------|------------------|
| `조직도본문.tsx` (650줄) | 메인 메뉴 라우터 (12개 메뉴 dynamic import), 연차촉진 알림 배너 | next/dynamic, leave-cycle, annual-leave-promotion |
| `조직도측면창.tsx` (1164줄) | 사이드바 + 모바일 하단 탭바, `SUB_MENUS` 카탈로그, 채팅 미읽음 배지 | access-control, 메신저데이터유틸, 알림센터 |
| `OrgChart.tsx` (1307줄) | 조직도 본체: 회사/부서/팀 트리, 근무중 현황, 실시간 동기화 | db, subscribeRealtime, profile-photo |
| `org-chart-types.ts` | 조직도 내부 타입 + 부서 스타일 상수 | — |
| `AddCompanyCard.tsx` | "새 회사·병원 추가" 안내 카드/모달 | — |

## 3. 기능별 상세 분석

### 3.1 메뉴 라우팅 (조직도본문)
- 12개 메뉴를 `next/dynamic`으로 lazy-load (`내정보/알림/조직도/채팅/게시판/전자결재/인사관리/재고관리/관리자/추가기능/공유캘린더/재무회계`).
- `MENU_LOADER_MAP` + `prefetchMenuModule()`로 사이드바 호버 시 on-demand prefetch.
- `mainMenu` 상태에 따라 해당 뷰를 렌더링. 각 뷰에 `user/staffs/posts/depts` 등 전역 데이터를 주입.
- **연차 촉진 알림 배너**: `leave-cycle.aggregateLedgerEntries` + `annual-leave-promotion.getStaffPromotionSchedule`로 잔여 연차 계산, 근로기준법 제61조 안내.

### 3.2 사이드바 (조직도측면창)
- `SUB_MENUS`에 메뉴별 서브메뉴 카탈로그 정의 (재고 4워크센터, 게시판 6종, 전자결재 4종, 인사 7워크센터, 관리자, 재무회계).
- `canAccessMainMenu`로 메뉴 노출 권한 필터링.
- 채팅 미읽음 배지: `fetchChatUnreadCountsByRoom`으로 실시간 집계.
- 모바일은 하단 탭바로 전환 (반응형).
- `NotificationCenter`(알림센터)를 사이드바에 내장.

### 3.3 조직도 본체 (OrgChart)
- 직원을 회사 → 사업부(Division) → 부서(Department)로 그룹핑. 부서별 고정 색상(간호=blue/진료=green/총무=orange/기타=violet).
- 리더 직책 키워드(대표이사/병원장/원장 등)로 리더/매니저 계층 분류.
- `subscribeRealtime`으로 출퇴근 상태 실시간 반영. "오늘 근무중" 요약(출근 후 미퇴근자) 표시.
- 검색/회사 필터/근무중만 보기 토글 제공.

## 4. 발견된 문제점 / 잠재 리스크

### 🟡 경미 (품질/리스크)
1. **라우터-조직도 역할 혼재** — `조직도본문.tsx`가 "조직도" 파일명이지만 실제로는 **전체 앱의 메뉴 라우터**다. 파일명과 책임 불일치로 신규 개발자가 혼동할 수 있음. (리팩토링 시 `AppRouter`/`메뉴셸` 분리 권장)
2. **`조직도측면창.tsx` 1164줄·`OrgChart.tsx` 1307줄** — 거대 컴포넌트. 사이드바에 알림센터/채팅배지/메뉴카탈로그가 모두 응집되어 있어 부분 수정 시 회귀 위험.
3. **`OrgChart.tsx`의 `org-chart-types.ts` 미사용 가능성** — `org-chart-types.ts`에 `OrgChartProps`/`DEPT_STYLES`/`toSafeText` 등이 정의되어 있으나, `OrgChart.tsx`는 자체 타입(`CompanyTree`/`DivisionGroup`)과 `DIVISION_STYLE_MAP`을 다시 정의. 중복 정의 가능성 → 더블체크 필요.
4. **부서 스타일 로직 중복** — `org-chart-types.ts`의 `DEPT_STYLES`(진료부=blue)와 `OrgChart.tsx`의 `getDivisionStyle`(진료부=green)이 **색상 매핑이 다름**. 한쪽은 미사용 잔재일 가능성.
