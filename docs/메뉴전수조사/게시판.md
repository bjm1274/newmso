## 1. 메뉴 개요

게시판은 공지사항/자유게시판/경조사/수술일정/MRI일정/업무가이드 6종 보드를 제공한다. 댓글(대댓글), 좋아요, 투표(경품·익명·복수선택), 첨부파일, 예약 발행, 읽음 추적, 태그, 즐겨찾기를 지원한다.

## 3. 기능별 상세 분석

### 3.1 글 작성 (create-board-post.ts)
- PC/모바일 공유 SSOT. `insertBoardPost` + optional-column fallback.
- 익명이어도 company/company_id 격리 유지, author_id는 staff_members.id 해석.
- 수술/MRI 일정은 content에 차트번호, title에 좌/우측 접두사, schedule_* 컬럼에 상세 메타 저장.

### 3.2 권한
- 수정: 작성자 본인 또는 부서장/시스템 마스터 (`canEditBoardPost`).
- 삭제: 작성자 본인 또는 시스템 마스터 (`canDeleteBoardPost`).
- 일정게시판 수정/삭제는 일반 직원이 **결재 요청(approvals insert, type='기타')**으로 상신하는 분기 존재.

### 3.3 조회수
- D1 RPC(`increment_post_views`) 우선 → 실패 시 Postgres RPC → 실패 시 select 후 수동 update. 3중 폴백.

### 3.4 투표/좋아요/댓글
- 투표: `board-poll-prize.ts`(BoardPoll 타입), `board-poll-vote.ts`(투표 토글), 익명/복수/경품 지원.
- 좋아요: `toggleBoardPostLike`, 낙관적 UI.
- 댓글: 대댓글 트리(roots/repliesByParent), 권한(작성자/특권자) 기반 삭제.

### 3.5 예약 발행
- `scheduled_publish_at` + `isScheduledNoticePending`로 예약 상태 판정. 예약 시점 도래 전 비공개 처리.

## 4. 발견된 문제점 / 잠재 리스크

### 🟡 경미 (품질/리스크)
1. **`게시판.tsx` 1814줄 과대** — 목록/상세/작성/조회수/일정결재/예약발행이 한 파일에 혼재.
2. **조회수 3중 폴백 로직** — D1→Postgres RPC→select+update. 데이터 무결성(동시성 증가 시 lost update) 위험. 트랜잭션 없이 마지막 select 값 기반 +1이라 동시 조회 시 누락 가능.
3. **일정결재요청 approvals 직접 insert** — 전자결재 메뉴를 우회해 게시판에서 직접 insert. 결재 문서 포맷/유효성 일관성은 더블체크 필요.
4. **`isVoiceBoardType` deprecated** — 항상 false 반환하는 잔재 함수 (dead code).
