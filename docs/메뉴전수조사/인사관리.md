# 메뉴 전수조사 보고서 — 인사관리 (HR)

> 조사 대상: `app/main/기능부품/인사관리.tsx` + `인사관리워크센터/` + `인사관리서브/` + `lib/hr-*.ts`, `lib/annual-leave-*.ts`, `lib/payroll-*.ts` (약 100+ 파일)

## 1. 메뉴 개요

인사관리는 6개 워크센터(구성원/근태/연차·휴가/급여/복지/계약·문서)로 구성된 인사 통합 메뉴다. 근태이상 감지는 근태 워크센터 내부 탭으로 통합.

## 3. 기능별 상세 분석

### 3.1 구성원 (MemberWorkcenter)
- KPI 4종(전체/신규입사/퇴사예정/평균근속), 탭 6종.
- StaffTable + StaffDrawer(프로필·인사이력 타임라인) 분리.
- 등록/수정은 레거시 `StaffListManager`(구성원현황) 위임.

### 3.2 근태 (AttendWorkcenter)
- 근태 현황 + 근태이상 감지(abnormal) 통합. 근무표 관련 별칭은 schedule 탭으로 라우팅.
- `lib/shift-resolution`, `lib/staff-shift-resolver`로 근무표·시프트 판정.

### 3.3 연차·휴가 (LeaveWorkcenter)
- `lib/leave-cycle.aggregateLedgerEntries`, `lib/annual-leave-promotion`로 연차 원장·촉진 계산.
- 내정보 연차휴가내역·조직도 연차촉진 배너와 **동일 계산 함수** 공유.

### 3.4 급여 (PayrollWorkcenter)
- `lib/payroll-*`, `ordinary-wage`, `severance-pay`, `social-insurance`, `withholding-tax-file`로 계산.
- 내정보 급여명세서와 `lib/payroll-slip-rows` 정본 공유.

### 3.5 복지 (WelfareWorkcenter) / 계약·문서 (DocsWorkcenter)
- 경조사/생일/면허자격/건강검진. 계약문서 전자서명.

## 4. 발견된 문제점 / 잠재 리스크

### 🟡 경미 (품질/리스크)
1. **레거시-신규 이중 구조** — `인사관리.tsx`에 `REMOVED_MENU_FALLBACKS`(한글→영문 매핑 60여 개)와 `인사관리워크센터/index.tsx`에 `KOREAN_ALIASES`가 별도로 존재. 메뉴 매핑이 두 곳에 분산되어 정합성 리스크.
2. **`MemberWorkcenter`가 레거시 `StaffListManager`(구성원현황) 위임** — 신규 워크센터 안에 레거시 컴포넌트 호출. props가 한글 컨벤션(`직원목록/선택사업체/보기상태`)이라 혼재.
3. **`인사관리.tsx`에 `as never` 캐스팅** — `staffs={인사직원목록 as never}` 등 타입 우회. 안전성 저하.
4. **급여 계산 로직 분산** — `lib/`에 10여 개 급여 파일 분산. 계산 정본 일치가 중요(내정보·인사·모바일 3곳).
