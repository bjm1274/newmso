# 메뉴 전수조사 보고서 — 관리자

> 조사 대상: `app/main/기능부품/관리자전용.tsx` + `관리자전용서브/` + `관리자워크센터/` + `app/main/admin-menu-config.ts` (약 43개 파일)

## 1. 메뉴 개요

관리자는 시스템 운영/권한/감사/백업/분석 화면을 제공하는 최고 권한 메뉴다. 결정 #45로 26장 → 6 워크센터(exec/company/roles/ops/forms/audit)로 통합했다.

## 3. 기능별 상세 분석

### 3.1 메뉴 라우팅 (관리자전용 + admin-menu-config)
- 영문 워크센터 6종(exec/company/roles/ops/forms/audit) + 시스템마스터센터 + 숨김 레거시 한글 id.
- `ADMIN_TAB_ALIASES` + `ADMIN_PARENT_SUBVIEW_MAP`으로 레거시 한글 id → 영문 워크센터 매핑.
- `normalizeAdminEntry`로 진입 탭 정규화. `getDisplayedAdminSubView`로 딥링크 subview 해석.
- 데스크톱 전용 안내(모바일 768px 미만). 단 알림자동화·팝업관리는 모바일 허용.

### 3.2 권한 게이팅
- `canAccessAdminSection`(한글 섹션 id) + `hasSystemMasterPermission`(9999 시스템마스터) 이중 게이팅.
- `ADMIN_WORKCENTER_SECTION`으로 영문 워크센터→한글 섹션 권한 매핑.

### 3.3 시스템마스터센터
- 시스템마스터 전용 화면(연차수동부여 등). 6워크센터에 미포함, 일반 관리자 비노출.

### 3.4 감사/백업/보안
- 감사로그(접근/일반), 급여이상치 감지, 데이터백업/초기화, 시스템마스터센터.

## 4. 발견된 문제점 / 잠재 리스크

### 🟡 경미 (품질/리스크)
1. **레거시-신규 이중 라우팅 구조** — `관리자전용.tsx`(한글 탭 흐름)와 `관리자워크센터/`(영문 워크센터)가 병존. `ADMIN_TAB_ALIASES`/`ADMIN_PARENT_SUBVIEW_MAP`/`ADMIN_WORKCENTER_SECTION` 등 매핑 테이블이 3곳에 분산.
2. **`ADMIN_TAB_ALIASES`가 양방향 혼재** — `양식빌더: '문서양식'`(한글→한글)와 `경영분석: 'exec'`(한글→영문)가 같은 맵에 혼재. 정규화 순서에 따라 결과가 달라질 수 있음.
3. **`관리자전용.tsx`의 `any` 타입** — `canAccessAdminTab(user: any, ...)`, `ComponentType<any>` 등 광범위 사용.
4. **데이터초기화/백업 등 위험 작업** — `onRefresh` 옵셔널 체이닝(`onRefresh ?? (() => {})`)으로 누락 시 무작동. 위험 작업의 확인 다이얼로그 여부는 개별 파일 확인 필요.
