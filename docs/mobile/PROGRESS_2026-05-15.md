- 배치4는 6개 목표 중 **4개 마이그레이션 + 2개 부적합 스킵**으로 마감.
- **트레이드오프**:

  - 비품장비대여관리 — 데스크탑에서 `hidden sm:table-cell`로 숨겼던 대여일 컬럼이 ResponsiveTable에서 모바일 카드 body로 노출(정보 풍부화).
- **다음 세션 배치5 후보** (인사관리서브 27개 중 비교적 표준적인 표 우선):

  - **expandable·필터 박힌 패턴은 사전 식별해서 제외** (건강검진관리 같은 회귀 방지).
