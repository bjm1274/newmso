## 결과

채팅방이 조회 실패 때 닫히거나 대화가 사라져 보이는 경로, 메시지 시각 정렬과 페이지 누락, 인사 자료 조회 실패 처리, 민감 자료 권한, 부분 저장, 급여 마감 우회를 수정했다. 카메라 사용과 자동 작업, 테스트 실행 구성도 보완했다.

수정은 소스와 테스트 환경에 반영했다. 운영 서버 배포, 운영 DB 마이그레이션, Electron 설치 파일 배포는 수행하지 않았다. 운영 데이터는 수정하거나 삭제하지 않았다.

실제 Electron 프로세스 종료 사건은 재현하지 못했다. 확인된 화면 초기화·반복 재로딩 결함은 수정했지만, 이를 실제 종료의 확정 원인으로 단정하지 않는다. 종료 원인·종료 코드 기록을 추가했다.

## 검증 내역

- 전체 ESLint: 오류 0개, 경고 0개로 통과.

- `npm run typecheck`: 통과. 빌드의 타입 검사 생략 설정과 별도로 전체 TypeScript 검사를 수행했다.
- `npm run build`: 통과. 최종 인사 오류 처리를 포함한 배포용 빌드 생성 완료.
- `npm run verify:regressions`: 12개 검사 그룹 통과. 운영 DB에 접근하지 않고 메모리 SQLite에서 실제 SQL 생성기, 정책, 저장 API, 어댑터 및 훅을 실행했다.
- `npm run verify:cron`: 스케줄 6개, 직접·간접 라우트 18개 통과.
- 신규 테스트 DB: 마이그레이션 33개 적용 및 재적용 시 중복 실행 없음 확인.
- 실제 SQLite 로그인: 정상 로그인, 잘못된 비밀번호 거부, 메인 화면 진입 3개 통과.
- 채팅·연차 UI: 실시간 메시지 표시, 타방 미읽음·미리보기 갱신, 지연 응답 후 최신 메시지 유지, 연차 탭·작업 조작 4개 통과. 이 검사는 합성 API 응답을 사용하는 UI 회귀 검사다.
- 배포용 빌드 브라우저 검사: 실제 로그인 3개, 카메라 정책 1개, 연차 UI 1개 등 5개 통과. 앞선 검사와 중복된 항목을 포함한다.
- `node --check server.mjs`, `node --check electron-app/main.js`, `git diff --check`: 통과.

브라우저 테스트의 연차 동기화 API에는 합성 직원이 실제 테스트 DB에 없어 실패 로그가 있었다. 해당 검사는 화면 조작 검사이며, 연차 정산 전체 통합 검증으로 해석하지 않는다. 모든 브라우저·운영 계정·기기 조합을 검사한 것은 아니다.

## DB 및 배포 반영

새 마이그레이션: `lib/db/migrations/0031_payroll_lock_and_chat_time.sql`

기존 자료를 재작성하지 않고 급여 잠금 트리거 3개와 채팅 시각 인덱스 2개를 추가한다. 일반 Next 서버의 SQLite 어댑터 초기화도 마이그레이션을 확인하고 실패 시 초기화를 중단하도록 했다. custom 서버도 기존 기동 마이그레이션 경로에서 적용한다.

운영 반영 시 서버 코드와 마이그레이션을 함께 배포해야 한다. 새 급여 잠금 방어는 운영 DB에 해당 마이그레이션이 적용된 뒤 유효하다. Electron의 종료 진단 추가는 새 설치 파일 반영이 필요하다.

Electron 로그 위치는 사용자 데이터 폴더의 `process-failures.log`다. 메시지 본문·인사자료·토큰을 기록하지 않고 프로세스 종류·종료 사유·종료 코드만 남긴다. 로그는 1MB 기준으로 이전 파일로 순환한다.

CI 변경은 현재 Node/SQLite 빌드물의 생성과 검증까지다. 서버로 자동 배포하지 않는다. 기존 `deploy:allerp` 명령도 이번 작업에서 실행하지 않았다.

## 남은 확인과 검증 제한

1. 실제 메신저 전송 시 Electron이 종료되는 사건의 현장 재현과 새 종료 로그 확인.
2. 운영 서버의 동시 사용자·장시간 연결·실제 카메라 기기·푸시 발송 검증.
3. 구형 `scripts/verify-policies.mjs` 전체 정책 하네스의 SQLite 이관. 기존 `verify:policies` 명령과 파일은 유지했다. 새 12개 그룹 검사는 기존 전체 정책 검사와 같은 범위라고 주장하지 않는다.
4. GitHub Actions 전체 원격 실행은 아직 수행하지 않았다. 로컬 명령 성공과 CI 파일 검토를 완료했다.

기존 권한 검사 명령을 새 회귀 검사로 대체하는 시도는 자동 승인 검토에서 보안 검사 범위 축소 우려로 거부됐다. 해당 대체 변경은 적용하지 않았고, 기존 검사를 유지하면서 별도 회귀 검사와 CI 단계만 추가했다.
