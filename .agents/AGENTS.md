# Antigravity Custom Rules (안티그래비티 기본 규칙)

- **언어 설정 (Language Setting)**: 모든 답변과 안내는 한국어(Korean)로 진행해야 합니다. 영어로 답변하지 마십시오.
- **보고서 작성 (Report Setting)**: 구현 계획서(implementation_plan.md), 작업 완료 설명서(walkthrough.md) 등 모든 산출물/보고서(Artifacts)도 한국어(Korean)로 작성해야 합니다.
- **데이터 격리 및 보안 절대 규칙 (Data Isolation & Security Rule)**: 다른 직원들의 대화 내역, 메시지, 알림 및 회사/조직/DB 정보가 교차 혼합되거나 누출되지 않도록 **100% 엄격한 테넌트 및 사용자 데이터 격리(Tenant & User Isolation)**를 보장해야 합니다. 모든 쿼리 및 UI 레이어에서 본인 권한에 속하지 않는 타인/타회사 데이터의 결합이나 노출을 원천 차단하십시오.
